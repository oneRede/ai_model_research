# Intern-S2-Preview: 科学智能体基础模型

<sup>†</sup>

Intern-S2-Preview Team, Shanghai AI Laboratory

###### 摘要

科学发现日益需要能够对异构模态的科学证据进行推理、与科学工具和环境交互，以及在长任务周期中持续推进的 AI 系统。我们提出了 Intern-S2-Preview，这是一系列科学智能体基础模型 (agentic foundation model)，旨在支持多模态科学理解、推理、生成和长周期任务。训练流水线始于科学多模态预训练，涵盖渲染的科学文档、交错图文数据 (interleaved image-text data) 以及多样化的科学语料。从预训练检查点开始，我们应用了统一的后训练流水线，包括监督微调、可扩展多任务强化学习 (RL)、黑盒与白盒智能体 RL，以及在策略蒸馏。该流水线采用了一系列实用技术来提升 rollout（采样生成）和训练的稳定性与效率，包括：带离策略校正 (off-policy correction) 的部分 rollout (partial rollout)、自适应长度正则化 (adaptive length regularization)、在线推测解码 (speculative decoding)、鲁棒多任务优化，以及面向智能体任务的轨迹感知经验组装 (trace-aware experience assembly)。在架构层面，Intern-S2-Preview-397B 将时间序列建模从高效长序列理解扩展到数值预测，而 Memory Decoder（记忆解码器）作为独立的记忆增强路径被研究，用于在不修改冻结的 397B 主干 (frozen backbone) 的情况下实现快速科学专业化。在科学、多模态、智能体和通用基准上的评估表明，Intern-S2-Preview-397B 在多个设置中取得了具有竞争力或领先的结果。时间序列模块在 SciTS 上改进了科学信号理解和预测，而独立的 Intern-MemDec-4B 扩展在不修改冻结的 397B 主干的情况下，将 Biology-Instructions 平均分数从 56.92 提升至 60.32。

## 1 引言

大语言模型和多模态基础模型的最新进展正在重塑 AI for Science 的发展，使模型能够对多样化的科学知识、观测数据和计算工具进行推理 [^72] [^36] [^8] [^112]。科学多模态模型和基准进一步扩展了这一方向，超越文本范畴，评估对科学图表、显微镜图像、遥感观测、地球科学现象和数值时间序列的感知、理解和推理 [^110] [^11] [^77] [^105] [^86]。然而，有意义的科学发现不仅仅是对孤立问题产生正确回答。它需要基于异构证据的持续推理和自适应规划，以及在长任务周期中与工具和外部环境的反复交互 [^70] [^80]。

现有的模型家族对于此类科学工作流仍不完整。通用 LLM [^2] [^58] 提供了广泛的指令遵循和推理能力，但并未针对异构科学模态、领域协议或可验证的工具交互进行专门化。科学多模态模型 [^8] [^112] 改进了对专门输入的感知和推理，但仍常被评估为静态问答系统，而非长周期智能体。这些局限性促使了 Intern-S2-Preview 的诞生，这是一系列科学智能体基础模型，旨在超越科学问答，转向迭代式、工具支撑的问题解决，其中 Intern-S2-Preview-397B 是本报告评估的主要模型。

在架构层面，我们关注科学智能体基础模型的两个互补需求。首先，科学工作流通常要求模型既能理解长数值信号，又能预测未来系统状态。因此，Intern-S2-Preview-397B 通过增加专用预测分支，将时间序列建模从高效长序列理解扩展到数值预测。其次，通常需要快速适应新的科学领域，模型应在不丧失其通用能力的情况下专门化到新领域。为解决这一问题，我们探索了一种无需重写模型参数的高效模型专业化策略，即将独立训练的参数化记忆 [^78] [^84] 附加到冻结的 397B 主干上，以引入额外的领域知识和专门化能力。

然后，Intern-S2-Preview 通过分阶段流水线进行训练。在持续预训练期间，我们关注科学文档和多模态语料，其信息分布在文本、图表、表格、方程和页面布局中。视觉预训练 (Visual Pre-training, VP) [^109] [^100] 通过预测视觉潜变量 (visual latents) 从渲染的科学页面中学习，使模型能够吸收在文本提取过程中往往被削弱的文档结构。同时，我们通过解析页面、裁剪视觉信息单元，并将文本和视觉元素恢复为布局感知的 (layout-aware) 序列来构建交错 PDF 数据，使用视觉增益过滤 (visual-gain filtering) 来保留视觉内容对语言建模有贡献的页面。我们进一步构建了大规模图像检索流水线，以召回和重排高质量科学图像用于多模态训练。这些阶段共同为预训练模型提供了科学文本、文档级视觉上下文和跨模态图像证据。

从预训练检查点开始，后训练将这些预训练能力转化为可控的推理、生成和智能体行为。监督微调为后续强化学习提供了指令遵循和工具使用的初始化。然后，我们在可验证目标下应用可扩展多任务强化学习，以改进异构科学和通用任务中的推理深度、正确性、科学生成和响应效率。该阶段由为长 rollout 和异构任务混合设计的系统和优化技术支持，包括带离策略校正的部分 rollout、自适应长度正则化、在线推测解码，以及 GEPO（群组级熵控制策略优化，Group-level Entropy-Controlled Policy Optimization）[^21]，用于平衡具有不同熵机制的任务组之间的探索和更新强度。

对于长周期智能体任务，我们基于**执行器 × 任务** (harness × task) 抽象引入了黑盒与白盒智能体 RL 框架<sup>1</sup>。该框架将智能体运行时与可执行任务分布解耦，并将语义动作-观测轨迹与 token 级 rollout 轨迹对齐，使得不同的工具使用智能体和可执行任务可以共享通用的 rollout、验证和训练协议。我们从编码和终端基准构建任务，并基于多样化社区技能的自演化通用任务合成系统 [^71] 构建任务。最后，在策略蒸馏将单独优化的推理和智能体专家策略整合到统一的 Intern-S2-Preview 模型中。

我们在科学、多模态、智能体、通用和时间序列基准上评估了 Intern-S2-Preview-397B。这些评估涵盖了静态科学问题解决和需要规划、工具使用和迭代执行的面向工作流的设置。结果表明，Intern-S2-Preview-397B 在单一基础模型中结合了通用理解、特定领域科学推理、科学生成和智能体交互。它在多个科学基准上获得了具有竞争力或领先的分数，在通用和多模态任务上获得了具有竞争力的开源模型结果，在时间序列理解和预测上获得了可衡量的增益，并在智能体编码、终端和面向研究的任务上表现出竞争力。我们还评估了生物学中的独立 Memory Decoder 变体，以检验在不修改 397B 主干的情况下的模块化专业化。

## 2 架构

Intern-S2-Preview-397B 通过升级的时间序列模块，将时间序列建模从科学信号理解扩展到数值预测。此外，Memory Decoder 提供了一条记忆增强的专业化路径，其中外部参数化记忆可以附加到冻结的 397B 主干上，而无需修改模型的核心参数。

### 2.1 Memory Decoder

Memory Decoder [^78] [^12] [^84] [^83] 是用于持续领域专业化的独立扩展模型，而非基础 Intern-S2-Preview-397B 模型的组成部分。如图 1 所示，它通过外部参数化记忆附加新知识和专门化能力，同时保持 Intern-S2-Preview-397B 主干冻结。在这种设计中，单独训练的记忆解码器通过其下一 token 分布的动态融合，以领域特定知识和能力补充主干。在每个解码步骤，一个轻量级 token 级路由器确定记忆解码器应贡献多少 [^78]。可以通过附加独立训练的记忆来引入新的科学能力，而无需修改 Intern-S2-Preview-397B 主干。

这种设计的动机源于科学专业知识的长尾分布和持续演化特性。尽管 Intern-S2-Preview-397B 为科学推理、指令遵循、多模态理解和工具增强问题解决提供了强大的通用基础，但没有固定的后训练检查点能够完全覆盖每个专业化子领域、任务协议或新兴领域。直接针对每个新领域微调主干是不理想的，因为改进领域性能的相同参数更新可能会扰动模型的通用推理、智能体行为和多模态能力。Memory Decoder 通过将领域扩展从主干重写转变为模块化记忆附加，避免了这种权衡。Intern-S2-Preview-397B 继续作为通用主干，而领域知识通过可插拔记忆 (plug-and-play memories) 提供，不会损害通用能力。

图 1：Intern-S2-Preview-397B 的独立 Memory Decoder 扩展的架构。冻结的 Intern-S2-Preview-397B 主干和领域记忆并行处理相同输入，并产生单独的下一 token 分布。轻量级 token 级路由器使用它们的隐藏状态和输出分布不确定性特征来预测动态融合权重 $\lambda$，该权重控制两个分布对最终预测的贡献。

##### 训练

Memory Decoder 通过将基于检索的领域证据压缩为可重用的参数化模块来训练。给定领域 SFT 语料 $\mathcal{D}_{\mathrm{sft}}=\{(q^{(i)},a^{(i)})\}_{i=1}^{N}$，我们在答案侧位置上构建 token 级数据存储。对于每个目标 token，前缀为 $c_{t}^{(i)}=[q^{(i)};y_{<t}^{(i)}]$，键为 $k_{t}^{(i)}=\phi(c_{t}^{(i)})$，值为 $y_{t}^{(i)}$，其中 $\phi(\cdot)$ 是冻结的。对该数据存储的最近邻检索提供了软下一 token 教师分布 [^40]：

$$
p_{\mathrm{ret}}(y\mid c_{t})\propto\sum_{(k_{j},v_{j})\in\mathcal{N}(k_{t})}\mathbb{I}_{y=v_{j}}\exp(-d(k_{t},k_{j})/\tau),
$$

其中 $\mathcal{N}(k_{t})$ 是检索到的邻居集合，$d(\cdot,\cdot)$ 是检索距离，$\tau$ 是温度参数。记忆训练将检索蒸馏与来自金标准答案 token 的监督相结合：

$$
\begin{gathered}\mathcal{L}_{\mathrm{mem}}(c_{t})=\beta\,\mathcal{L}_{\mathrm{KL}}(c_{t})+(1-\beta)\mathcal{L}_{\mathrm{CE}}(c_{t}),\\[-1.0pt]
\mathcal{L}_{\mathrm{KL}}(c_{t})=\mathrm{KL}(p_{\mathrm{ret}}(\cdot\mid c_{t})\|p_{\mathrm{mem}}(\cdot\mid c_{t})),\quad\mathcal{L}_{\mathrm{CE}}(c_{t})=-\log p_{\mathrm{mem}}(y_{t}\mid c_{t}).\end{gathered}
$$

这里 $\beta\in[0,1]$ 平衡检索教师和金标准 SFT 答案。通过这一目标，Memory Decoder 学习将领域知识和重复出现的任务模式捕获为可插拔参数化记忆。

##### 推理

在记忆增强变体的推理时，Intern-S2-Preview-397B 和 Memory Decoder 并行处理相同的解码上下文。对于前缀 $c_{t}=[x;y_{<t}]$，冻结的 Intern-S2-Preview-397B 主干产生 $p_{\mathrm{S2}}(\cdot\mid c_{t})$，而记忆解码器产生 $p_{\mathrm{mem}}(\cdot\mid c_{t})$。轻量级 token 级路由器接收来自两个模型的隐藏表示以及置信度和熵特征，并预测融合系数 $\lambda_{t}\in[0,1]$。最终的下一 token 分布为

$$
p_{\mathrm{final}}(\cdot\mid c_{t})=(1-\lambda_{t})p_{\mathrm{S2}}(\cdot\mid c_{t})+\lambda_{t}p_{\mathrm{mem}}(\cdot\mid c_{t}).
$$

在路由器训练期间，Intern-S2-Preview-397B 和 Memory Decoder 保持冻结，仅优化路由器，使用领域和通用指令数据的混合。除了融合分布上的交叉熵外，我们对记忆权重应用带符号线性正则化器：

$$
\begin{gathered}\mathcal{L}_{\mathrm{CE}}(c_{t})=-\log p_{\mathrm{final}}(y_{t}\mid c_{t}),\qquad\mathcal{R}(c_{t})=s_{t}\lambda_{t},\\
\mathcal{L}_{\mathrm{router}}(c_{t})=\mathcal{L}_{\mathrm{CE}}(c_{t})+\alpha_{s}\mathcal{R}(c_{t}).\end{gathered}
$$

其中对于领域样本 $s_{t}<0$，对于通用样本 $s_{t}>0$，$\alpha_{s}>0$ 控制正则化强度。

### 2.2 时间序列模块

#### 2.2.1 升级的时间序列编码器用于高效长序列建模

科学时间序列通常在序列长度、采样频率和通道依赖性方面表现出显著变化，这使得高效且表达性强的建模具有挑战性。Intern-S2-Preview-397B 在 Intern-S1-Pro 的基础上升级了时间序列编码器，改进了长序列处理效率并增强了多通道表示学习。

如图 2(a) 所示，输入时间序列首先被划分为时间块，以实现长序列的局部化处理。每个块由压缩分块模块处理，该模块由归一化、基于 CNN 的局部特征提取和基于 Q-Former 的时间压缩组成。在归一化期间，通道级均值和标准差被保留为辅助统计量。提取的局部表示然后被划分为时间补丁，其中每个补丁通过带有可学习查询的 Q-Former 压缩为固定数量的 token。通过根据输入长度动态调整时间分块过程，编码器为异构长时间序列维持可控的输出序列长度。与 Intern-S1-Pro 中的时间序列编码器直接通过均值池化聚合多通道表示不同，Intern-S2-Preview-397B 引入了通道级 Transformer 编码器，在输入 Transformer 编码器主体进行全局时间上下文建模之前，对通道间依赖性进行建模。时间序列编码器与 LLM 之间的连接保持不变。

与 Intern-S1-Pro 中使用的先前版本相比，升级后的编码器将支持的最大输入长度从约 240,000 增加到 300,000 个时间步。在最大序列长度下，它实现了约 $5\sim 6\times$ 更快的推理速度，同时将 GPU 内存消耗降低到先前版本的约 20%。除了改进长序列处理外，新架构还支持对高频但短序列长度信号的有效建模，这是 Intern-S1-Pro 不支持的设置。这种能力进一步扩展了时间序列模块的学科覆盖范围，将其现有的天文学、地球科学、神经科学、生理信号分析和生物声学支持扩展到包括雷达信号分析（$\sim$ MHz）。

#### 2.2.2 时间序列生成模块

除了时间序列理解，时间序列预测 (time series forecasting) 对科学应用至关重要，因为它使模型能够预测未来系统状态并支持更广泛的科学任务。Intern-S2-Preview-397B 集成了时间序列预测模块，以在多模态 LLM 框架内实现统一的时间序列理解和生成。通过引入专用数值预测分支，而非将值生成为离散文本 token，模型在保持计算效率的同时保留了数值保真度。

如图 2(b) 所示，预测模块引入了一个以 LLM 和时间序列编码器的多模态表示为条件的预测分支。来自 LLM 的语义上下文和来自时间序列编码器的数值时间表示通过 Q-Former 选择性提取，并通过交叉注意力整合以调节因果 Transformer 预测器进行未来序列生成。视野预测器进一步解释预测指令并确定所需的预测长度，实现跨不同视野的灵活预测。

## 3 预训练

科学语料以文本和视觉两种形式包含知识。除了扩展文本 token 之外，Intern-S2-Preview 通过保留文档布局、将视觉单元与周围科学上下文链接，以及检索高质量视觉样本用于多模态训练，来强化其科学数据基础。

### 3.1 视觉预训练

除了以文本为中心的科学训练之外，Intern-S2-Preview 引入了视觉预训练 (Visual Pre-training, VP) 作为模态扩展的轻量级阶段。遵循 [^109] [^100]，VP 从渲染为页面图像的大规模无标签科学文档中学习，保留在文本提取期间可能丢失的图表、表格、方程和布局信息。如图 3 所示，VP 通过直接从同一文档语料的视觉表示中学习，来补充传统的文本预训练。

![Refer to caption](https://arxiv.org/html/2608.13505v1/vp_pipeline.png)

图 3：匹配文本和视觉预训练的概述。文本路径从解析的 PDF 内容预测 token，而视觉路径从渲染的页面预测前景视觉潜变量，改进文本和视觉文档表示之间的对齐。

给定页面图像 $\mathcal{I}$，冻结的视觉编码器提取视觉特征序列 $\mathcal{Z}=E_{\mathrm{v}}(\mathcal{I})=(z_{1},\ldots,z_{N})$。前景掩码 (foreground mask) $m_{i}$ 去除空白区域，之后保留的特征按光栅扫描顺序 (raster-scan order) 排列。生成的序列投影到 LLM 隐藏空间并进行自回归建模：

$$
\mathcal{U}=\operatorname{RasterScan}\{z_{i}\mid m_{i}=1\}=(u_{1},\ldots,u_{L}),\qquad L\leq N,
$$

$$
\hat{u}_{t+1}=\psi\!\left(\left[\Phi_{\theta}\left(W_{\mathrm{in}}u_{\leq t}\right)\right]_{t}\right).
$$

这里，$W_{\mathrm{in}}$ 表示视觉输入投影，$\Phi_{\theta}$ 是自回归 LLM 主干，$\psi$ 是轻量级视觉预测头。VP 使用对比下一潜变量预测目标进行训练。对于预测和目标索引 $t,j\in\mathcal{B}$，它们的温度缩放余弦相似度和匹配概率为

$$
s_{tj}=\frac{\hat{u}_{t+1}^{\top}u_{j+1}}{\tau\lVert\hat{u}_{t+1}\rVert_{2}\lVert u_{j+1}\rVert_{2}},\qquad p_{tj}=\frac{\exp(s_{tj})}{\sum_{k\in\mathcal{B}}\exp(s_{tk})}.
$$

VP 损失定义为

$$
\mathcal{L}_{\mathrm{VP}}=-\frac{1}{|\mathcal{B}|}\sum_{t\in\mathcal{B}}\log p_{tt},
$$

其中 $u_{t+1}$ 是 $\hat{u}_{t+1}$ 的正目标，$\mathcal{B}$ 中的其余目标作为批内负样本。在持续预训练期间，文本和视觉样本在联合目标下交错：

$$
\mathcal{L}=\lambda_{\mathrm{text}}\mathcal{L}_{\mathrm{CE}}+\lambda_{\mathrm{vis}}\mathcal{L}_{\mathrm{VP}}.
$$

视觉编码器保持冻结，而 LLM 主干、视觉投影和预测头被优化。由于监督直接从视觉特征获得，VP 既不需要 OCR 和布局解析，也不需要配对数据和人工标注。因此，它为文本预训练提供了可扩展的补充，保留了支持语言和多模态科学能力的文档结构和视觉模式。

### 3.2 交错图文数据

在多模态大模型的预训练中，仅构建图文对不足以完全覆盖真实世界 PDF 文档的多模态理解需求。现有的多模态预训练策略严重依赖图像字幕数据，这捕获了图像与局部文本片段之间的语义对齐，使其适用于物体识别、图像描述和局部视觉-语义建模。然而，PDF 中更关键的信息通常在于图像、方程、表格和周围文本之间的上下文关系，包括布局位置、视觉元素前后的解释段落、文本引用、跨页推理链，以及长文档中知识的渐进组织。因此，我们进一步从 PDF 构建交错图文数据，如图 4 所示，使模型不仅能学习图像描绘的内容，还能学习它如何嵌入文档叙述并参与知识表达和推理。

具体而言，我们首先应用 MinerU2.5-Pro [^76] 对 PDF 文档进行 OCR 和布局感知结构解析。该系统识别每个页面上的文本块、标题、段落和视觉信息区域。对于视觉内容，我们关注三种类型的单元：常规图像、行间方程和表格。每个视觉单元根据其边界框从原始 PDF 页面裁剪，并保存为标准化子图像。然后我们构建页面级交错序列。对于每个页面，文本块和视觉单元根据布局阅读顺序和边界框顺序重新组织，形成页面级序列。为了进一步选择具有真正视觉依赖性的高价值页面，我们引入了基于视觉增益的质量过滤机制。受 Toolformer [^64] 启发，我们在两种条件下计算页面文本的语言模型困惑度：不含视觉输入的纯文本条件，以及包含图像、表格或方程的交错条件。视觉增益 (visual gain) 定义为两种困惑度之间的差异。添加视觉信息后 PPL 的显著降低表明视觉内容为理解页面提供了有意义的支持。装饰性图像、广告或弱相关视觉元素通常产生低视觉增益，而包含实验图表、机制图、结构插图、表格或方程的科学页面通常导致 PPL 显著降低。因此，我们结合人工审查和特定领域阈值，仅保留视觉增益超过相应阈值的页面。

最后，我们按原始 PDF 页面顺序连接过滤后的页面级交错序列以形成文档级序列，进一步拆分为适合长上下文 VLM 预训练的块，每个块上限为 256k token，并共享 512 token 的重叠。该流水线专注于生命科学、化学和材料科学，为 VLM 预训练产生高质量交错图文数据。

### 3.3 图像检索增强

检索高质量数据是准备文本预训练语料的常见做法。然而，检索高质量图像数据的流水线尚未得到充分探索。因此，如图 5 所示，我们引入了大规模图像检索流水线来召回高质量数据，并在训练期间提高它们的采样比例，以增强模型的多模态能力。

该流水线依赖于构建大规模图像向量数据库。主要流程包括：1) 从交付的数据源中提取图像及其关键元数据，并根据图像的 SHA256 值进行去重，以确保向量数据库中图像的唯一性；2) 使用 8B 嵌入模型对图像进行编码并生成 1024 维嵌入表示；3) 为了平衡数亿规模数据的存储和检索性能，基于 Milvus 向量数据库构建多个集合，并将图像向量分片存储，以支持后续的高性能检索。

##### 在线检索阶段

系统支持两种检索模式：文本到图像检索和图像到图像检索。对于两种模式，采用与向量构建阶段相同的嵌入模型进行向量编码，以保持向量空间的一致性。

对于不同类型的输入，处理流程如下：

- 图像输入：直接对输入图像进行编码以获得其图像嵌入；同时，使用字幕模型 [^88] 生成图像的文本描述，然后将字幕文本编码为向量。通过这种方式，从视觉和语义两个角度进行联合检索，提高了召回率和语义匹配能力。
- 文本输入：直接使用嵌入模型生成文本向量，并在图像向量数据库中执行跨模态相似度检索。

##### 召回后的后处理阶段

为了进一步提高检索结果的质量，系统对召回结果应用后处理，包括：过滤重复样本，使用重排器 (reranker) 模型对候选结果进行重排并分配质量分数，以及利用分数最终过滤检索结果。

## 4 后训练

### 4.1 后训练框架

从预训练检查点开始，我们为 Intern-S2-Preview 开发了统一的后训练流水线。该流水线增强了通用推理、指令遵循、工具使用和长周期智能体行为，同时进一步改进了科学智能的三大核心能力：科学推理、跨科学模态的生成，以及科学智能体问题解决。

如图 6 所示,流水线由三个主要阶段组成。我们首先在高质量演示的广泛混合上执行监督微调，以建立基本推理行为、响应格式、科学生成能力和工具使用模式。然后，我们在多样化的科学和通用任务上进行可扩展多任务强化学习，以进一步改进推理、生成和科学能力。同时，我们应用黑盒智能体强化学习在交互环境中培养专门化策略，其中模型通过外部工具和环境反馈解决复杂任务。最后，我们采用在策略蒸馏将通用和专门化策略获得的能力整合到单一统一模型中。

### 4.2 监督微调

第一个后训练阶段在应用强化学习之前，将预训练模型转换为可控助手。我们在涵盖广泛领域和交互设置的大规模高质量多模态数据集上执行监督微调。数据混合包括通用对话、指令遵循、安全对齐、代码生成和推理、图文理解、视觉感知和空间定位、工具使用、专门化科学任务，以及长周期智能体轨迹。这种多样化的监督使模型在通用和科学场景中都具备强大的基础能力。

为确保数据质量，我们应用了广泛的过滤、清理和去重程序。对于需要显式推理的任务，我们通过使用我们的上一代模型 Intern-S1-Pro 以及其他领先的开源模型进行拒绝采样，构建高质量思维链演示。生成的样本进一步由语言模型和人类领域专家验证，以改进事实正确性、推理质量和格式一致性。这一精心策划的 SFT 阶段为后续强化学习阶段提供了强大而稳定的初始化。

### 4.3 可扩展且稳定的强化学习

SFT 之后，强化学习用于在可验证目标下改进正确性、推理深度、科学生成和响应效率。扩展强化学习流水线引入了几个实际挑战。Rollout 生成是强化学习中的主要计算瓶颈。部分和异步 rollout 还会引入需要仔细控制的离策略效应。此外，平衡推理效率与模型性能仍然困难，而多任务训练中的优化冲突可能会阻碍跨领域的稳定收敛。为应对这些挑战，我们引入了带离策略校正的部分 rollout、自适应长度正则化、用于更快 RL rollout 的推测解码，以及鲁棒多任务优化。以下各节详细描述了我们后训练框架的各个组件。#### 4.3.1 带离策略校正的高效部分 Rollout

长推理强化学习特别容易受到响应长度长尾分布的影响。在同步 rollout 流水线中，少量异常长的生成可能延迟整个批次的完成，导致大多数 GPU 在等待落后者时处于空闲状态 [^111] [^62] [^30]。现有系统通常通过以下两种方式解决这一问题：要么将训练和推理共置并使用部分 rollout [^67] [^111] [^62]，要么将 rollout 生成和策略优化完全分离到不同的 GPU 池 [^30]。

在评估了不同 RL 阶段的计算特性和我们的基础设施后，我们基于 XTuner 训练引擎和 LMDeploy 推理引擎开发了一个共置的部分 rollout 系统。如图 7 所示，推理引擎在 rollout 生成期间持续接收新请求以保持高 GPU 利用率。一旦完成的轨迹数量足以形成一个训练批次，剩余的进行中 rollout 会在其当前生成位置暂停，而不是中止或丢弃。它们已生成的前缀和 rollout 元数据会被保留，同时相同的 GPU 池从推理切换到策略训练。策略更新后，训练状态被卸载，更新后的模型参数同步到推理引擎，暂停的请求从其保留的前缀恢复生成。只有完成的轨迹才会被纳入当前训练批次。

这种暂停-恢复机制避免了等待长尾生成，同时保留了已在未完成响应上花费的计算。它还避免了在完全异步系统中分离训练和推理资源时常见的生产者-消费者平衡问题。然而，由于恢复的轨迹可能包含在一个或多个策略更新之前和之后生成的片段，同一轨迹内的不同 token 可能来自不同的行为策略版本。因此，我们为每个采样 token 记录行为策略版本和生成时的对数概率。

对于轨迹 $i$ 中的 token $y_{i,t}$，我们将重要性采样比率定义为

$$
\rho_{i,t}(\theta)=\frac{\pi_{\theta}(y_{i,t}\mid s_{i,t})}{\pi_{\mathrm{beh}(i,t)}(y_{i,t}\mid s_{i,t})},
$$

其中 $\pi_{\mathrm{beh}(i,t)}$ 表示生成 token $y_{i,t}$ 的行为策略版本，$\pi_{\theta}$ 表示当前学习策略。我们明确限制轨迹的陈旧度：如果轨迹中最旧的保留片段是在当前学习器三次策略更新之前生成的，则该轨迹将被丢弃。

遵循 [^55] 的裁剪重要性权重公式，我们将重要性比率截断为

$$
\bar{\rho}_{i,t}(\theta)=\operatorname{clip}\left(\rho_{i,t}(\theta),1-\epsilon_{\mathrm{low}}^{\mathrm{IS}},1+\epsilon_{\mathrm{high}}^{\mathrm{IS}}\right).
$$

裁剪后的比率随后在 REINFORCE 目标中用作分离的重要性权重。与 PPO 风格的裁剪不同（PPO 裁剪代理目标，可能完全抑制来自信任区域外 token 的梯度），裁剪重要性权重在限制更新方差的同时，为每个未被掩码的 token 保留非零的策略梯度贡献。

对于 MoE 策略，训练-推理不一致性既来自专家路由差异，也来自两个执行引擎之间的数值差异。我们采用 Rollout Router Replay (R3) [^52] 来解决前者：LMDeploy 在 rollout 期间做出的专家选择被记录下来，并在 XTuner 评估相应 token 时重放。这确保了 rollout 和训练遵循相同的专家路径。遵循 Intern-S1-Pro [^112]，我们还使用对齐的混合精度配置，其中专家线性层以 FP8 运行，其余层使用 BF16，而数值敏感操作（包括 apply\_rope、RMSNorm、MoE 路由器、Gated DeltaNet [^95] 中的循环状态以及语言模型头）以 FP32 计算。

在路由重放和算子级对齐之后，仍有少量 token 可能因残余数值差异而表现出较大的概率差异。受 KPop [^44] 启发，我们使用双向二元 KL 散度来检测这些异常值。设 $p_{i,t}^{\mathrm{train}}$ 和 $p_{i,t}^{\mathrm{rollout}}$ 表示训练和 rollout 引擎在匹配的模型参数和重放的路由决策下产生的采样 token 概率。我们定义

$$
D_{\mathrm{BKL}}(p\|q)=p\log\frac{p}{q}+(1-p)\log\frac{1-p}{1-q},
$$

并构造 token 掩码

$$
m_{i,t}^{\mathrm{BKL}}=\mathbb{I}\left[D_{\mathrm{BKL}}\left(p_{i,t}^{\mathrm{train}}\|p_{i,t}^{\mathrm{rollout}}\right)\leq\phi\right]\mathbb{I}\left[D_{\mathrm{BKL}}\left(p_{i,t}^{\mathrm{rollout}}\|p_{i,t}^{\mathrm{train}}\right)\leq\phi\right].
$$

R3 消除了离散的专家路由不匹配，而 BKL 掩码过滤了剩余的 token 级数值异常值。方程 (11) 中的裁剪重要性权重和方程 (13) 中的 token 掩码被纳入第 4.3.5 节描述的统一 RL 目标中。

图 7：基于 XTuner 和 LMDeploy 的共置部分 rollout 系统概览。在 rollout 期间，完成的请求被持续替换以保持推理引擎充分利用。一旦收集到足够的完成轨迹来形成一个训练批次，剩余的进行中 rollout 会被暂停，并保留其已生成的前缀。然后相同的 GPU 切换到策略训练。训练状态卸载并将更新后的模型权重同步到推理引擎后，暂停的请求从其保留的前缀恢复生成。

#### 4.3.2 用于高效推理的自适应长度正则化

长思维链推理模型经常在相对简单的问题上表现出过度思考，即使正确解决方案可以用少得多的计算达到，也会产生不必要的长推理轨迹 [^16] [^61]。现有方法通过显式的长度感知奖励或约束 [^73] [^3]、查询自适应的长度惩罚 [^87]，或单独的长度控制微调阶段 [^49] [^103] 来提高推理效率。虽然有效，但基于奖励的方法引入了可能与任务奖励冲突的辅助优化目标，而额外的微调阶段使后训练流水线复杂化，并可能干扰在早期 RL 阶段获得的能力。

我们引入了一种自适应长度正则化方法，该方法直接重新加权正样本响应的优势，而不添加独立的奖励信号。该方法遵循两个原则。首先，我们不对负样本响应施加长度正则化。由于错误的响应可能因许多不同原因而失败，惩罚其长度可能会过早抑制潜在有用的探索，从而降低模型性能。其次，仅当模型在相应查询上达到足够高的通过率时，我们才激活长度正则化。这种设计允许模型自由探索困难查询，并仅在基本掌握它们后才鼓励简洁推理。

对于每个查询 $q$，设 $\mathcal{G}_{q}=\{1,\ldots,G\}$ 索引 $G$ 个采样响应的组，设 $\hat{A}_{i}$ 表示响应 $i$ 的原始优势。我们将正样本响应集定义为

$$
\mathcal{P}_{q}=\left\{i\in\mathcal{G}_{q}\mid\hat{A}_{i}>0\right\}.
$$

正则化后的优势由下式给出

$$
\widetilde{A}_{i}=\begin{cases}\displaystyle\frac{\sum_{j\in\mathcal{P}_{q}}\hat{A}_{j}}{\sum_{j\in\mathcal{P}_{q}}w_{j}\hat{A}_{j}+\epsilon}w_{i}\hat{A}_{i},&i\in\mathcal{P}_{q},\;|\mathcal{P}_{q}|\geq\tau G,\\[12.0pt]
\hat{A}_{i},&\text{otherwise},\end{cases}
$$

其中 $\tau$ 控制激活长度正则化所需的正样本响应的最小比例。长度相关权重 $w_{i}$ 定义为

$$
w_{i}=\alpha+(1-\alpha)\left(1-\frac{L_{i}-L_{\min}^{+}}{L_{\max}^{+}-L_{\min}^{+}+\epsilon}\right)^{\gamma},\qquad i\in\mathcal{P}_{q},
$$

其中

$$
L_{\min}^{+}=\min_{j\in\mathcal{P}_{q}}L_{j},\qquad L_{\max}^{+}=\max_{j\in\mathcal{P}_{q}}L_{j},
$$

其中 $L_{i}$ 是响应 $i$ 的推理长度，$\alpha$ 指定分配给长响应的最小权重，$\gamma$ 控制长度相关衰减的形状，$\epsilon$ 确保数值稳定性。

在正样本响应中，较短的解决方案获得更大的权重，而较长的解决方案被降权但保留正优势。归一化项近似保留了总正优势质量，从而改变了成功响应之间的相对偏好，而不会显著改变整体优化规模。如果正样本响应比例低于 $\tau$，或者如果响应具有非正优势，则其优势保持不变。因此，该方法自适应地从困难查询的探索过渡到模型已经掌握的查询的效率优化。

如图 8 所示，我们比较了使用和不使用自适应长度正则化训练的 Intern-S2-Preview-35B。两种设置都达到了可比的奖励曲线，而自适应长度正则化显著减少了平均输出长度。这些结果表明，所提出的方法在不牺牲模型性能的情况下提高了推理效率。

#### 4.3.3 用于更快 RL Rollout 的推测解码

尽管共置的部分 rollout 系统显著提高了 GPU 利用率，但 rollout 生成仍然是 RL 训练中最耗时的阶段之一，因为长推理轨迹仍必须自回归生成。推测解码为加速此过程提供了一种补充方法。轻量级草稿模型首先提出多个候选 token，然后由当前策略模型通过精确拒绝采样过程并行验证 [^43] [^14]。由于此验证过程保留了策略模型的采样分布，推测解码加速了 rollout 生成而不引入额外的离策略偏差。最近的研究通过并发感知的在线草稿学习、持续演化的草稿模型、树结构 rollout 缓存以及与 RL 基础设施的系统级集成，探索了用于 RL rollout 的推测解码 [^101] [^15] [^13] [^37]。

将推测解码应用于 RL 的核心挑战在于策略模型在训练期间持续演化。因此，固定的草稿模型随着策略更新变得越来越陈旧，导致其输出分布之间的不匹配不断增长，token 接受率逐渐下降。为解决此问题，我们使用最新策略生成的轨迹在线训练草稿模型。在每次 RL 迭代中，草稿模型使用当前策略在新收集的 rollout 状态上的 token 分布进行更新，同时通过策略模型停止梯度。这种在线适应允许草稿模型在整个 RL 训练过程中持续跟踪演化的 rollout 分布。

我们使用混合 LK Loss [^63] 训练草稿模型，该损失结合了正向 KL 散度的稳定优化行为和全变差距离的直接接受率优化。对于 rollout 状态 $s_{t,k}$ 处的第 $k$ 个草稿位置，我们将目标策略和草稿模型分布表示为

$$
p_{t,k}(v)=\operatorname{sg}\left[\pi_{\theta}(v\mid s_{t,k})\right],\qquad q_{t,k}(v)=\pi_{\phi}^{\mathrm{draft}}(v\mid s_{t,k}),
$$

其中两个分布都在 rollout 采样温度下计算，$\operatorname{sg}[\cdot]$ 表示停止梯度算子。正向 KL 散度和全变差距离分别定义为

$$
D_{\mathrm{KL}}\left(p_{t,k}\,\|\,q_{t,k}\right)=\sum_{v\in\mathcal{V}}p_{t,k}(v)\log\frac{p_{t,k}(v)}{q_{t,k}(v)},
$$

和

$$
D_{\mathrm{TV}}\left(p_{t,k},q_{t,k}\right)=\frac{1}{2}\sum_{v\in\mathcal{V}}\left|p_{t,k}(v)-q_{t,k}(v)\right|.
$$

在无损推测采样下，期望 token 接受概率等于目标分布和草稿分布之间的重叠：

$$
\alpha_{t,k}=\sum_{v\in\mathcal{V}}\min\left(p_{t,k}(v),q_{t,k}(v)\right)=1-D_{\mathrm{TV}}\left(p_{t,k},q_{t,k}\right).
$$

遵循混合 LK 公式，我们将两个散度目标组合为

$$
\mathcal{L}_{\mathrm{LK}}^{(t,k)}=\lambda_{k}D_{\mathrm{KL}}\left(p_{t,k}\,\|\,q_{t,k}\right)+\left(1-\lambda_{k}\right)D_{\mathrm{TV}}\left(p_{t,k},q_{t,k}\right).
$$

混合系数由接受率自适应确定：

$$
\lambda_{k}=\exp\left(-\eta\,\operatorname{sg}\left[\bar{\alpha}_{k}\right]\right),\qquad\eta>0,
$$

其中 $\bar{\alpha}_{k}$ 是在序列和批次维度上聚合的第 $k$ 个草稿位置的接受率。完整的在线草稿训练目标为

$$
\mathcal{L}_{\mathrm{draft}}=\frac{1}{K}\sum_{k=1}^{K}\frac{1}{|\mathcal{T}_{k}|}\sum_{t\in\mathcal{T}_{k}}\mathcal{L}_{\mathrm{LK}}^{(t,k)},
$$

其中 $K$ 是预测的草稿位置数量，$\mathcal{T}_{k}$ 包含第 $k$ 个草稿步骤的有效训练位置。在我们的实现中，草稿模型在 $K=4$ 个未来位置预测 token，我们将自适应系数超参数设置为 $\eta=3$。

当草稿模型与当前策略对齐不佳时，接受率 $\bar{\alpha}_{k}$ 较低，$\lambda_{k}$ 接近 1。因此目标由正向 KL 项主导，该项为快速将草稿分布与演化的策略对齐提供平滑且良好缩放的梯度。随着草稿模型变得更好对齐且接受率增加，$\lambda_{k}$ 降低，TV 分量获得更大权重。由于最小化 TV 距离等价于最大化分布重叠，目标逐渐从稳定的分布匹配转向直接接受率优化。

通过在线草稿适应和混合 LK 目标，接受率随着 RL 训练的进展而持续提高，而不是随着策略演化而降低。在我们的大规模训练运行中，推测解码最终在 rollout 生成中提供了约 $2\times$ 的加速，在整个 RL 训练流水线中提供了 $1.7\times$ 的端到端加速。这些结果表明，在线草稿学习提供了一种无损且有效的加速机制，补充了我们的部分 rollout 系统。

#### 4.3.4 鲁棒多任务优化

我们在异构任务混合上对 Intern-S2-Preview 执行 RL，这些任务在结构、解决方案多样性和策略探索的不确定性方面存在差异。这在相同策略下引发了不同的熵机制，使得全局或 token 级熵调节不足以满足其异构探索需求 [^94] [^66] [^20] [^22]。这种异构性进一步使基于组的策略优化方法引入熵依赖偏差，使跨提示组的优势信号在统计上不可比。

我们应用群组级熵控制策略优化 (GEPO) [^21]，该方法使用直接从现有分组样本估计的群组级熵作为诊断信号，以识别和缓解熵异构性引起的优化偏差。具体来说，GEPO 衰减低熵组中的正优势以防止过度利用进一步扩大熵差距，同时衰减高熵组中的负优势以避免过早抑制探索。这种缩放是不对称的，因为低熵组更容易受到激进干预的影响（可能触发长度崩溃），因此需要比高熵组更温和的衰减。

在 GRPO 和 RLOO 中，给定对每个提示 $x$ 从 $\pi_{\theta}(\cdot|x)$ 采样的组响应 $\{y_{1},\ldots,y_{K}\}$，我们将群组级熵定义为

$$
H_{\text{g}}(x)\;=\;-\frac{1}{K}\sum_{i=1}^{K}\sum_{t=1}^{T_{i}}\log\pi_{\theta}(y_{i,t}\mid y_{i,<t},x).
$$

然后，我们对每个响应的原始优势 $\{A_{i}\}_{i=1}^{K}$ 进行重塑

$$
\hat{A}_{i}=\omega(g,A_{i},\mathcal{H}_{\text{g}})A_{i}=\begin{cases}\alpha_{\text{low}}\cdot A_{i}&\text{if }A_{i}>0\ \text{and}\ \mathcal{H}_{\text{g}}(x)<\mathcal{H}_{\text{low}}^{(t)},\\
\alpha_{\text{high}}\cdot A_{i}&\text{if }A_{i}<0\ \text{and}\ \mathcal{H}_{\text{g}}(x)>\mathcal{H}_{\text{high}}^{(t)},\\
A_{i}&\text{otherwise},\end{cases}
$$

其中 $\alpha_{\text{high}}\in(0,1)>\alpha_{\text{low}}\in(0,1)$ 是缩放系数，$\mathcal{H}_{\text{low}}^{(t)}$ 和 $\mathcal{H}_{\text{high}}^{(t)}$ 表示训练步骤 $t$ 处的下限和上限熵阈值。

GEPO 不是强制异构任务朝向共享的熵目标，而是保留任务依赖的探索机制，同时重新平衡它们对策略更新的有效贡献。它既不需要显式的任务注释也不需要额外的 rollout，可以直接集成到现有的基于组的策略优化流水线中，为异构后训练任务的稳定联合优化提供可扩展机制。

#### 4.3.5 统一 RL 目标和训练配置

我们的推理 RL 遵循 Intern-S1-Pro [^112] 中使用的留一法 REINFORCE 公式，并增加了上述引入的稳定性和效率技术。对于每个查询，我们采样一组 $G$ 个响应并获得它们的序列级验证器奖励 $\{R_{i}\}_{i=1}^{G}$。遵循 DAPO [^96] 的动态采样策略，奖励完全相同的查询组会在线过滤掉并用新采样的组替换。对于每个保留的组，初始留一法优势计算为

$$
A_{i}^{\mathrm{LOO}}=R_{i}-\frac{1}{G-1}\sum_{\begin{subarray}{c}j=1\\
j\neq i\end{subarray}}^{G}R_{j}.
$$

然后我们应用前面部分描述的两种优势重塑机制。GEPO 首先根据群组级熵调整组相对优势，以平衡异构任务之间的探索。随后将自适应长度正则化应用于熵调整后的优势，仅对正样本响应比例超过激活阈值的查询组鼓励更短的成功推理轨迹。用于策略优化的最终优势可以总结为

$$
\widetilde{A}_{i}=\mathcal{R}_{\mathrm{len}}\left(\mathcal{R}_{\mathrm{GEPO}}\left(A_{i}^{\mathrm{LOO}}\right)\right),
$$

其中 $\mathcal{R}_{\mathrm{GEPO}}$ 和 $\mathcal{R}_{\mathrm{len}}$ 分别表示上述定义的熵控制和自适应长度正则化变换。这种顺序确保长度相关权重作用于最终的熵调整优势，而不是修改验证器奖励。

给定部分 rollout 训练缓冲区 $\mathcal{B}$，我们使用以下方式优化策略

$$
\mathcal{L}_{\mathrm{RL}}(\theta)=-\mathbb{E}_{\left(q,\{y_{i}\}_{i=1}^{G}\right)\sim\mathcal{B}}\left[\frac{1}{G}\sum_{i=1}^{G}\frac{1}{|y_{i}|}\sum_{t=1}^{|y_{i}|}m_{i,t}^{\mathrm{BKL}}\,\operatorname{sg}\left[\bar{\rho}_{i,t}(\theta)\right]\widetilde{A}_{i}\log\pi_{\theta}\left(y_{i,t}\mid s_{i,t}\right)\right],
$$

其中 $\bar{\rho}_{i,t}$ 是方程 (11) 中定义的裁剪 token 级重要性权重，$m_{i,t}^{\mathrm{BKL}}$ 是方程 (13) 中定义的数值一致性掩码，$\operatorname{sg}[\cdot]$ 表示停止梯度算子。序列级优势 $\widetilde{A}_{i}$ 由响应 $y_{i}$ 中所有策略生成的 token 共享。

该目标结合了三种互补的稳定机制。裁剪重要性权重校正由暂停-恢复部分 rollout 和重复小批量更新引入的策略不匹配。R3 对齐 rollout 和训练引擎的专家路由决策，而 BKL 掩码在路由和算子对齐后移除剩余的数值异常值。同时，GEPO 和自适应长度正则化重塑序列级优势以平衡任务依赖的探索和推理效率。推测解码保留策略的采样分布，因此加速 rollout 生成而不修改方程 (29)。

我们使用 Muon 优化器 [^39] [^48]，学习率为 $1\times 10^{-6}$，权重衰减为 $0.01$。每个 rollout 批次包含 $8{,}192$ 个完成的响应，并通过 8 个小批量更新步骤进行优化。最大生成长度设置为 $65{,}536$ 个 token。总之，该训练配置和上述稳定机制支持在异构科学和通用任务上进行高效且稳定的推理 RL。

### 4.4 大规模黑盒和白盒智能体 RL

推理 RL 改进了单响应和面向生成的行为，但科学智能体还必须从涉及工具、文件、外部程序和环境反馈的交互会话中学习。我们围绕**执行器 × 任务抽象**开发了一个统一的智能体 RL 框架，该抽象将智能体执行接口与任务分布解耦。执行器指定智能体如何被实例化、驱动和观察，而任务指定初始环境、可执行目标和验证器定义的结果。它们的组合将异构智能体执行转换为 RL 经验的通用形式：具有显式环境、可观察的动作-观察历史和自动结果信号的交互式 rollout。

这种表述允许智能体训练沿两个互补轴扩展。沿执行器轴，我们支持控制循环可以直接编排的白盒实现，以及通过其原生 CLI、SDK 或模型 API 集成的黑盒运行时。沿任务轴，我们涵盖专门的编码和终端环境，以及由自演化任务合成系统产生的通用任务。由此产生的框架扩展了智能体行为和任务分布，同时保留了统一的 rollout、验证和训练协议。

最近的智能体 RL 系统强调了将智能体执行与策略优化解耦以及从异构智能体运行时恢复可训练经验的重要性 [^50] [^89] [^10]。Intern-S2-Preview 建立在我们关于智能体学习和评估的一系列研究之上。Agent-FLAN 研究了有效智能体调优的数据和优化；Lagent 提供了构建语言智能体的模块化框架；T-Eval 和 CIBench 研究了逐步工具使用和可执行代码解释器行为；MindSearch 研究了长时程信息搜索和整合；SciExplore 将智能体评估扩展到现实的科学导航和跨源综合 [^19] [^42] [^17] [^98] [^18] [^70] [^106]。最近的工作研究了通过过程延续学习进行行为对齐、无思维链监督下的下一块 RL 和 SFT 的作用，以及通过技能图和渐进验证进行自演化任务合成 [^28] [^29] [^69] [^71] [^102] [^32]。总之，这些努力促成了这里开发的**执行器 × 任务抽象**：一个可以独立改变智能体运行时和任务分布，同时保留统一 rollout、验证、轨迹组装和 RL 优化的通用系统。

#### 4.4.1 统一智能体 RL 基础设施

如图 9 所示，我们的基础设施由统一 rollout 运行时和轨迹感知经验组装层组成。前者将异构执行器与可执行任务组合，并在通用会话契约下运行它们；后者将语义轨迹和验证器反馈与策略优化所需的精确 token 级证据结合起来。

**统一执行运行时**。在 rollout 时，智能体 Rollout 运行器接收执行器-任务对，配置其执行环境，并管理交互直到正常完成或终止条件。执行器驱动智能体，而判断器适配器对相同的会话状态和执行工件执行结果验证和过程标注。共享沙箱提供者抽象了跨本地、远程和自定义后端的环境创建、命令和工具执行、隔离、错误处理和资源清理。因此，智能体控制、环境配置和验证可以独立演化，并在任务之间重新组合，而无需为每个配对构建定制的 rollout 流水线。

**执行器无关的智能体集成**。智能体网关和适配器在白盒、黑盒和自定义执行器实现之上暴露稳定接口。白盒循环可以直接编排，而黑盒执行器（包括 OpenClaw、Claude Code、OpenCode、OpenHands 和 Mini-SWE）保留其原生消息、工具循环和控制流 [^79] [^92]。适配器转换会话生命周期事件、模型调用和交互工件，而无需运行时访问或重新实现执行器的内部智能体逻辑。因此，添加新执行器只需要一个薄的集成适配器，而不是新的 RL 执行栈。

**客户端透明、训练感知的模型服务**。不同的黑盒执行器期望不同的模型协议。我们的 LLM 服务层接受 OpenAI Chat Completions、OpenAI Responses 和 Anthropic Messages，并支持常规和流式生成。请求由网关规范化并转发到分布式推理工作器，而流式文本、推理和工具调用事件以其原生形式中继到执行器。从客户端角度来看，这仍然是一个普通的模型服务。同时，服务层透明地捕获仅供训练使用的证据，包括精确的输入和输出 token ID、rollout 对数概率以及 token 级 MoE 路由器专家，而不向智能体的控制逻辑暴露这些扩展。

该服务路径实现了 token 级输入输出 (TITO) 接口。对于每个模型调用，会话服务器重用已为会话记录的精确 token 化前缀，仅对新附加的上下文进行 token 化，并将结果 token ID 直接发送到推理引擎。返回的 token 和策略统计信息从传递给智能体的相同响应流中捕获。对于稀疏 MoE 模型，Rollout Router Replay (R3) 还记录 rollout 时的专家选择以在训练期间重用。因此，TITO 保留了采样的 token 序列，而 R3 保留了产生它的条件计算路径。

图 9：我们的智能体 RL 基础设施概览。异构白盒和黑盒智能体由智能体网关统一，并针对共享沙箱和模型服务基板执行。语义轨迹和验证器反馈保留在重放缓冲区中，而 Rollout 轨迹存储通过每会话增量 PrefixTree 保留精确的 token 级证据。经验组装对齐两个视图以进行优势估计和策略优化。

**轨迹感知经验组装**。rollout 运行时产生交互的两个互补视图。智能体运行器和判断器适配器产生语义经验——动作-观察轨迹、结果奖励、过程标注和会话元数据——这些保留在重放缓冲区中。LLM 服务产生模型执行证据——token ID、损失标签、行为对数概率和路由器专家——这些写入 Rollout 轨迹存储。保持这些视图分离将面向环境的逻辑与特定于模型的训练表示解耦，同时保留从智能体动作到生成它的策略 token 的无损路径。

轨迹存储将每个会话组织为增量 PrefixTree。每个节点表示新附加的上下文增量或助手响应，并存储其 token ID、标签、rollout 对数概率和路由器专家。最长前缀匹配重用会话的稳定历史，仅附加新观察到的片段。当选择轨迹进行训练时，存储实现相应的根到叶路径。系统指令、用户消息和工具观察从损失中掩码，而合格的策略生成片段保留其训练标签。

除了增量存储外，PrefixTree 还保留跨多轮和分支交互的模型调用的谱系和精确边界。因此它在语义智能体动作与其 rollout 时 token 跨度之间建立了稳定的对应关系。经验组装通过会话和片段连接重放缓冲区记录和 token 轨迹，计算优势，并将模型就绪的经验导出到通用 RL 训练器。这种对应关系还为下面描述的过程感知奖励分配提供了基础。#### 4.4.2 智能体任务构建

单个技能通常描述局部工作流，而通用智能体必须在更长的时间范围内协调多种能力。因此，我们构建了一个技能-状态图，其节点表示可观察的环境状态，其边表示从技能中提取的状态转换能力。只有当技能的输入和输出状态兼容时，才会进行组合。从该图中采样不同长度的路径会产生具有不同时间范围和复杂度的能力序列。

每个采样的路径通过一个渐进式流水线转换为可执行任务包，该流水线依次构建环境、任务和验证器。每个阶段都配有一个可执行验证器。基于规则的检查验证结构正确性、依赖解析和可执行性，而基于评分标准的检查评估语义质量和跨阶段一致性。失败会触发阶段级修复或重新生成，只有经过验证的产物才会传递到下游。这使合成错误局部化，并减少环境、任务规范和验证器之间的不一致。

经过验证的任务被部署在在线 RL 中，并且也被 rollout 以构建可重用的离线训练数据。通过基于结果的过滤的候选轨迹会经历步级精选。每个交互步骤都按行为类型进行标注，涵盖正常进展以及工具使用错误、重复失败尝试、无效恢复、过早终止、协议违规、不支持的假设和幻觉观察。错误步骤保留在交互上下文中，但可以标记为跳过并从模仿损失中排除，而其余响应作为优化目标。这种选择性掩码避免了模仿有缺陷的中间行为，同时不破坏后续动作的因果上下文。

下游执行进一步暴露了合成任务分布中的系统性弱点。我们按技能领域和合成阶段聚合执行失败和验证器反馈，并使用这些统计数据更新技能采样权重以及合成技能、环境模板和阶段特定提示。修订后的系统然后重新采样能力路径并生成下一个任务分布，根据观察到的智能体行为逐步改进可执行性、覆盖范围和难度。

图 10：通用智能体任务的自演化构建。社区技能经过过滤并通过兼容的技能-状态路径进行组合，然后分阶段合成产生经过验证的任务包。在线和离线 rollout 产生精选的可重用轨迹，而执行失败更新采样和合成组件以生成下一个任务分布。

#### 4.4.3 鲁棒智能体 RL 训练

在智能体经验上进行优化引入了超越单轮响应优化的挑战。验证器对完整的、工具交错的会话进行评分，而只有选定的策略生成片段是可训练的。此外，可执行环境将奖励通道暴露给解决方案泄露、测试操纵和其他形式的奖励黑客攻击。我们首先将终端结果与会话的可训练片段对齐，然后用过程感知优势控制细化此信号，最后强化验证器以防止奖励泄露。我们最后通过检查跨任务族和智能体执行器的优化行为来总结。

会话感知结果归功。智能体会话可能包含由系统指令、用户消息、工具调用和环境观察分隔的多个助手响应。然而，这些片段共同解决一个任务并接收一个最终结果奖励。在同一任务的每个 rollout 组内，我们根据群组相对优化范式 [^65]，从 rollout $i$ 的完整会话奖励计算群组相对优势 $A_{i}$。相同的会话优势被分配给其轨迹中的所有符合条件的策略生成片段，而不是将每个模型调用视为独立奖励的片段。token 级标签从损失中排除非策略上下文，而 PrefixTree（前缀树）保留可训练响应片段的精确边界。

过程感知优势控制。当会话最终成功时，仅基于结果的归功可能会强化不良的中间行为，尽管存在格式错误的输出、无效或重复的工具调用、不必要的恢复尝试或异常终止。我们将结果评估和过程反馈分开，反映了结果监督和过程监督之间的区别 [^47]。结果验证器确定任务是否已解决，而过程标注器将 adv\_penalty 附加到表现出确定性过程错误的特定助手消息。这些标注不会改变会话奖励或 token 标签。

![Refer to caption](https://arxiv.org/html/2608.13505v1/assets/agentic_rl_reward_overview.png)

图 11：在多个智能体执行器下，SWE、通用和终端任务的奖励轨迹。每个面板展示了 160 个优化步骤的代表性示例。曲线经过局部平滑以突出整体优化趋势。

PrefixTree 将每个标注的消息映射到其精确的可训练 token 范围。设 $w_{i,k}\in[-1,1]$ 表示会话 $i$ 中片段 $k$ 的过程权重。对于该片段中的可训练 token $t$，我们使用

$$
\widetilde{A}_{i,k,t}=\begin{cases}w_{i,k}A_{i},&A_{i}>0,\\
A_{i},&A_{i}\leq 0,\end{cases}
$$

并将非可训练 token 的优势设为零。过程权重可以抑制或反转解析和格式错误、无效工具名称或参数、重复或失败的工具调用以及上下文、轮次或会话限制终止的正面归功。它们仅应用于正优势，因此失败轨迹的负学习信号得以保留。简而言之，结果奖励确定任务是否已解决，而过程权重确定中间行为是否应该获得正面归功。

验证器完整性和泄露防护。对于可执行编码任务，我们将智能体可见的执行产物与仅用于评分的信息隔离开来。黄金补丁、保留测试和精确评分测试标识符从 rollout 工作空间中排除，并且仅在智能体执行后提供给评分基础设施。仓库历史被清理为单个基线提交，并删除远程引用，防止智能体通过 Git 元数据恢复目标修复。在必要时，直接揭示上游 issue 的任务标识符同样从面向智能体的指令中省略。

在评估期间，规范测试文件在智能体停止后被恢复或覆盖，黄金测试补丁应用在智能体的源代码更改之上。因此，对智能体可见测试的修改不能直接改变评分过程。我们对软件工程任务使用保守的全部正确语义，要求目标修复和回归检查都通过；对于具有规范预期测试状态映射的任务，观察到的结果必须完全匹配。缺少的评分产物、执行失败和不可解析的验证器输出与真正的任务失败分别跟踪，防止基础设施错误被解释为成功的策略行为。总之，这些措施使奖励与可执行任务状态的真实变化相关联，而不是访问隐藏解决方案或验证器损坏。

跨任务和执行器的优化。相同的训练和经验组装路径用于软件工程、通用和终端任务，而不为每个执行器引入特定任务的 RL 流水线。图 11 总结了代表性的奖励轨迹。通用任务对于 Claude Code 和 OpenClaw 都快速改进然后稳定。更长时间范围的 SWE 和终端任务表现出更多依赖执行器的瞬态，但它们显示的轨迹在优化窗口内改进或恢复。这些不同的动态是预期的：执行器决定交互策略和上下文构建，而任务决定环境和奖励语义。因此，共享的上升趋势证明了通用轨迹、归功分配和优化堆栈在不同的执行器-任务组合中保持有效，而不是证明它们的绝对奖励尺度是直接可比的。

### 4.5 在策略蒸馏

最后阶段将分别优化的推理和智能体策略的互补优势合并到发布的统一模型中。尽管混合强化学习使单个策略能够获得广泛的能力，但联合优化高度异构的推理和智能体任务可能会引入优化冲突，并阻止模型充分利用特定领域的训练信号。因此，我们从相同的 SFT 检查点分别训练两个专家策略：通过混合推理 RL 获得的推理专家和通过大规模黑盒和白盒智能体 RL 获得的智能体专家。然后，我们采用在策略蒸馏 (OPD) 将它们的互补能力整合到单个统一模型中。与先前训练大量细粒度领域专家的多教师方法 [^51] [^56] [^108] [^107] 不同，我们围绕两个广泛的能力领域组织专业化。我们的初步评估表明，为许多细粒度领域独立训练教师会产生大量的 RL 和基础设施成本，同时为我们的设置提供有限的额外收益。双专家设计在专业化质量、训练成本和蒸馏复杂性之间实现了有利的平衡。

OPD 中的一个关键挑战是学生与其教师之间的分布不匹配。由于教师是在学生采样的前缀上进行评估的，因此较大的策略差异可能导致学生轨迹落在教师的可靠支持范围之外，从而导致嘈杂或无信息的监督。在我们的设置中，两个专家策略都源自相同的 SFT 检查点，因此保持了广泛兼容的生成行为。为了进一步减少初始差异，我们遵循 Nemotron 3 Ultra [^56] 中引入的预热策略。具体来说，我们使用推理和智能体专家生成高质量轨迹，并对原始 SFT 模型执行轻量级 SFT 预热。生成的检查点作为 OPD 的初始学生。这种预热使学生在 OPD 优化开始之前接触到两位教师的特征推理模式和交互行为，增加了学生生成的轨迹与教师支持的分布之间的重叠。

在 OPD 期间，每个查询被分配给推理或智能体领域，并选择相应的专家作为其教师。设 $d\in\{\mathrm{rea},\mathrm{agt}\}$ 表示领域，$\mathcal{D}_{d}$ 表示其提示分布，$\pi_{T_{d}}$ 表示相应的教师策略。给定查询 $q$，学生策略 $\pi_{\theta}$ 首先生成在策略轨迹 $y$，所选教师评估学生生成的前缀 $s_{t}=(q,y_{<t})$。遵循 Nemotron 3 Ultra [^56]，完全在策略的目标最大化负反向 KL 散度：

$$
\mathcal{J}_{\mathrm{OPD}}(\theta)=\sum_{d\in\{\mathrm{rea},\mathrm{agt}\}}\lambda_{d}\mathbb{E}_{q\sim\mathcal{D}_{d},\,y\sim\pi_{\theta}(\cdot\mid q)}\left[\sum_{t=1}^{H}\left(\log\pi_{T_{d}}(y_{t}\mid s_{t})-\log\pi_{\theta}(y_{t}\mid s_{t})\right)\right],
$$

其中 $\lambda_{d}$ 控制每个领域的采样或损失权重，$H$ 表示轨迹长度。等价地，该目标最小化

$$
D_{\mathrm{KL}}\left(\pi_{\theta}(\cdot\mid s_{t})\,\|\,\pi_{T_{d}}(\cdot\mid s_{t})\right)
$$

在学生本身诱导的状态上。与基于稀疏轨迹级奖励的 RL 目标相比，OPD 在整个生成轨迹中从相应专家提供密集的 token 级监督。

现有的 OPD 系统可能在每个 token 位置传输完整的教师分布或其 top-$k$ 近似 [^23] [^51]。然而，对于我们最大 256K token 的序列长度，这些方法的通信和存储成本变得可观。在教师评分工作器和学习器工作器之间传输每个位置的完整词汇表 logits 甚至 top-64 教师 logits 都会引入很大的通信负载。由于我们的教师共享相同的 SFT 起源，并且预热阶段进一步减少了它们与学生的策略差异，我们发现仅传输每个采样 token 的教师对数概率就足以进行稳定蒸馏。这将教师负载从 $O(HV)$ 或 $O(Hk)$ 减少到 $O(H)$，其中 $V$ 是词汇表大小，$k$ 是保留的教师 logits 数量。

为了支持由我们的部分 rollout 基础设施产生的轨迹上的策略更新，我们使用与推理 RL 中相同的裁剪重要性加权 REINFORCE 公式。唯一的区别在于优势的构建。对于每个采样的 token $y_{i,t}$，我们将采样 token 蒸馏优势定义为

$$
\widehat{A}_{i,t}^{\mathrm{OPD}}=\operatorname{sg}\left[\log\pi_{T_{d}}\left(y_{i,t}\mid s_{i,t}\right)-\log\pi_{\mathrm{prox}}\left(y_{i,t}\mid s_{i,t}\right)\right],
$$

其中 $\pi_{T_{d}}$ 是分配给领域 $d$ 的教师，$\pi_{\mathrm{prox}}$ 是用于构建蒸馏信号的冻结近端学生策略，$\operatorname{sg}[\cdot]$ 表示停止梯度算子。当教师对采样 token 分配的概率高于近端学生时，优势为正，否则为负，从而相应地增加或减少采样动作的概率。

如等式 (10) 所示，token 级重要性采样比直接在当前学习器策略和生成该 token 的行为策略版本之间定义：

$$
\rho_{i,t}^{\mathrm{OPD}}(\theta)=\frac{\pi_{\theta}\left(y_{i,t}\mid s_{i,t}\right)}{\pi_{\mathrm{beh}(i,t)}\left(y_{i,t}\mid s_{i,t}\right)}.
$$

我们使用与推理 RL 相同的区间裁剪该比率：

$$
\bar{\rho}_{i,t}^{\mathrm{OPD}}(\theta)=\operatorname{clip}\left(\rho_{i,t}^{\mathrm{OPD}}(\theta),1-\epsilon_{\mathrm{low}}^{\mathrm{IS}},1+\epsilon_{\mathrm{high}}^{\mathrm{IS}}\right).
$$

设 $\mathcal{B}_{d}$ 表示分配给领域 $d$ 的部分 rollout 批次，$N_{d}$ 表示来自该领域的轨迹数量，$\mathcal{T}_{i}$ 表示轨迹 $i$ 中策略生成的 token 位置集合。我们使用以下方式优化学生：

$$
\mathcal{L}_{\mathrm{OPD}}(\theta)=-\sum_{d\in\{\mathrm{rea},\mathrm{agt}\}}\lambda_{d}\mathbb{E}_{\mathcal{B}_{d}}\left[\frac{1}{N_{d}}\sum_{i=1}^{N_{d}}\frac{1}{|\mathcal{T}_{i}|}\sum_{t\in\mathcal{T}_{i}}m_{i,t}^{\mathrm{BKL}}\,\operatorname{sg}\left[\bar{\rho}_{i,t}^{\mathrm{OPD}}(\theta)\right]\widehat{A}_{i,t}^{\mathrm{OPD}}\log\pi_{\theta}\left(y_{i,t}\mid s_{i,t}\right)\right],
$$

其中 $\lambda_{d}$ 控制每个教师领域的贡献，$m_{i,t}^{\mathrm{BKL}}$ 是推理 RL 中使用的相同数值一致性掩码。非策略 token，包括提示、环境观察、工具输出和填充 token，通过 $\mathcal{T}_{i}$ 排除。

等式 (36) 与等式 (29) 中的统一推理 RL 目标具有相同的优化形式。在两种情况下，当前策略都使用分离和裁剪的行为到当前重要性权重进行优化，以及 R3 路由对齐和基于 BKL 的数值掩码。唯一的区别是优势：推理 RL 使用从验证器奖励、GEPO 和自适应长度正则化派生的序列级优势，而 OPD 使用等式 (33) 中的 token 级教师-学生对数概率差。

通过共享初始化、教师轨迹预热和采样 token 在策略监督，我们的方法避免了完整词汇表或 top-$k$ 蒸馏的复杂性和通信开销，同时在长轨迹上保持稳定优化。生成的学生将混合推理策略的科学推理能力和智能体策略的长时间范围交互能力整合到统一的 Intern-S2-Preview 模型中。

## 5 评估

我们进行了广泛的实验，从两个角度在各种基准测试上评估 Intern-S2-Preview-397B：科学任务和通用任务，涵盖纯文本和多模态设置。在本节中，我们首先介绍评估设置，然后简要描述所使用的基准测试。然后，我们将 Intern-S2-Preview-397B 的性能与其他最先进的模型进行比较。

### 5.1 基准测试

#### 5.1.1 科学基准测试

Biology-Instructions [^34] 是一个多组学基准，评估模型跨不同生物尺度的序列理解能力。它将基于生物序列的预测任务与高级推理要求相结合，挑战模型解释复杂的基因组、转录组和蛋白质组数据。

Mol-Instructions [^27] 旨在通过三个主要类别弥合专业 LLM 训练的差距：面向分子、面向蛋白质和面向生物分子文本的任务。它包含大量指令遵循对，促进模型处理复杂生物分子结构和功能描述的熟练度。

MolecularIQ [^9] 评估语言模型对表示为 SMILES 的分子图进行忠实推理的能力。它包含 5,111 个符号可验证的问题，涉及 849 个结构保留的分子，并将它们组织成计数、索引和约束生成任务族。其采样过程平衡了推理深度、多任务负载、分子复杂性和答案分布，能够对分子结构推理中的失败进行细粒度定位。

SciReasoner [^80] 评估跨不同学科的科学推理，包括物理、化学和医学，共 9 个领域和 149 个具体任务。它由十个子基准的统一套件组成，具有不同的问题格式，如选择题、填空题和基于协议的程序性问题，旨在评估知识检索和复杂演绎推理。

TOMG-Bench [^45] 评估开放域、自然语言引导的分子生成。它包括三个主要任务——分子编辑、分子属性优化和定制分子生成——每个任务分为三个子任务，每个子任务有 5,000 个测试样本。自动评估框架测量生成的分子是否有效、是否满足请求的结构或属性约束，以及是否保持适当的相似性或新颖性。

MP20 是一个针对每个单位晶胞最多 20 个原子的材料的条件晶体结构生成基准。该任务需要在周期性和对称性等物理约束下从化学成分预测精确的原子坐标和晶格参数。它包含 27,136 个训练样本和 9,046 个测试样本，提供了真实结构目标，但没有思维链推理标注。

ProteinBinder-9 是一个专注的基准，用于评估针对九个生物学相关蛋白质靶标的从头蛋白质结合剂设计。该基准按照 ODesign（一种用于生物分子相互作用设计的全原子生成世界模型 [^99]）引入的蛋白质-蛋白质相互作用设计设置的精神设计。对于每个靶标，任务是生成满足预定义结合界面并通过多阶段结构和物理化学评估流水线的蛋白质结合剂。候选主链和序列使用互补的计算模型生成和评估，包括 RFdiffusion [^82] 等结构生成方法和 AlphaFold 3 [^1] 的生物分子复合物预测。生成的候选项使用界面置信度、结合能和分子接触标准进一步评估。ProteinBinder-9 涵盖了不同的靶蛋白和界面几何形状，从而测试设计系统是否可以超越单个蛋白质家族或结构背景进行泛化。我们报告了通过每个靶标完整评估程序的候选项的数量和比例，以及所有九个靶标的汇总结果。ProteinBinder-9 旨在为评估端到端蛋白质结合剂设计系统提供可重现的测试平台，而不是孤立的序列生成或结构预测性能。

XLRS-Bench [^77] 专注于极大、超高分辨率遥感 (RS) 图像；该基准定义了 16 个子任务来评估 6 种类型的感知能力和 4 种类型的推理能力。它挑战多模态大语言模型 (MLLM) 处理复杂的语义关系并促进高分辨率地理空间场景中的真实世界决策。

MicroVQA [^11] 专注于基于显微镜的研究，由 1,042 个专家精选的选择题组成，涵盖多种成像模式。该基准评估生物工作流中的三种关键推理能力：专家图像理解、假设生成和实验提议。

SFE [^110] 是一个专家级基准，包含 830 个经过验证的视觉问答 (VQA) 对，跨越 66 个多模态任务。该数据集跨越五个高价值科学学科，利用真实的原始科学数据格式来探测模型在感知、理解和高级推理方面的认知能力。

ObsCrisis-Bench [^57] 评估从多光谱卫星观测和可选气象站测量中对极端天气和地球物理危机的多模态推理。其官方数据集卡报告了 4,202 个视觉问答样本，涵盖 127 个事件、八个灾害类别和 61 个国家。任务跨越多个观测时间步骤的早期预警、事件类型和时间预测、影响评估和事件后恢复分析。

SciCode [^75] 评估语言模型为现实科学研究问题编写可执行代码的能力，而不是传统的算法练习。它包含 80 个主要问题，分解为 338 个子问题，跨越 16 个科学子领域，包括物理、数学、材料科学、生物学和化学。每个问题结合了科学知识、推理和代码合成，并附带可选的背景材料、科学家编写的参考解决方案和可执行测试。

SGI-Bench [^90] 评估实践探究模型定义的完整探究周期中的科学通用智能：审议、概念、行动和感知。它包含 1,263 个专家精选的样本，跨越十个科学领域和 75 个研究方向，组织成科学深度研究、想法生成、干湿实验和多模态实验推理。特定任务的多维指标评估证据综合、新颖性和可行性、计算正确性、协议保真度和实验结果解释。

ResearchClawBench [^91] 评估自主智能体是否可以从原始数据和相关文献进行端到端的科学研究，直到出版风格的研究报告。它包含 40 个任务，来自十个科学领域的真实论文，同时在评估期间保留目标论文。专家撰写的多模态评分标准测量智能体是否重现了原始实验协议、证据链、分析和科学结论，同时为超出源论文的发现留出空间。我们在 ResearchHarness v0.0.49 上评估了 ResearchClawBench。#### 5.1.2 通用基准

MMLU-Pro [^81] 通过增加选项数量并聚焦于更具挑战性、推理密集型的问题，增强了原始 MMLU 基准。它涵盖广泛的学科领域，要求模型展示更深层次的多任务语言理解和更稳健的问题解决能力。

SimpleQA-Verified [^33] 在不访问检索工具的情况下评估短格式事实性和参数化知识。它包含 1,000 个经过人工验证的提示，这些提示通过去重、主题平衡、来源协调、歧义消除和对抗难度过滤从 SimpleQA 派生而来。其改进的自动评分器能够区分正确、错误和未尝试的响应，同时更可靠地处理数值容差、模糊表述和答案格式变化。

AdvancedIF [^35] 在复杂的单轮指令、多轮上下文延续和系统提示可控性条件下评估高级指令遵循能力。它包含 1,645 个人工编写的提示，配有专家撰写的评分标准，每个标准包含多达 20 个可独立验证的条件。仅当响应满足所有适用条件时才算成功，这使得该基准对用户级、对话级和系统级指令中的细微遗漏和冲突非常敏感。

HMMT-2026 [^24] 使用来自 2026 年 2 月哈佛-麻省理工数学竞赛（通过 MathArena 发布）的 33 个问题评估高级数学推理能力。这些问题涵盖代数、组合数学、几何和数论，已转换为 LaTeX 格式并与参考答案一起进行人工验证。由于这些问题在竞赛后不久即被评估，该基准也可作为竞赛级数学问题解决的相对新鲜测试。

MMMU-Pro [^97] 是 MMMU 基准的稳健扩展版本。MMMU-Pro 引入了更具挑战性的多学科多模态任务，强调跨广泛专业领域的专家级理解和复杂推理，利用高分辨率图像和专业知识。

ChartQAPro [^53] 评估对真实图表的视觉感知和复杂推理能力。已发布的基准包含从 99 个不同来源收集的 1,341 个图表和 1,948 个问题，涵盖数学和视觉推理、对话查询、事实核查、多项选择题和假设场景。它包括仪表板、信息图、地图、条形图和折线图等异构图表类型，相比早期的图表问答数据集大幅提高了视觉和语言多样性。

SkillsBench [^46] 评估程序化知识的结构化包是否能提升语言模型智能体在专业密集型任务上的性能。其当前清单包含跨 8 个领域的 87 个任务，每个任务都配有精心策划的技能 (Skills) 和确定性验证器。该基准使用有无技能的配对评估来分离程序化指导的贡献与底层模型和智能体执行器 (harness) 的贡献。我们在 OpenClaw 2026.5.7 上评估了 SkillsBench。

Terminal-Bench 2.1 [^54] [^74] 在隔离的命令行环境中评估智能体执行 89 个困难的真实任务，涵盖软件工程、机器学习、安全、数据科学及相关工作流。每个任务提供专用环境、人工编写的参考解决方案和用于结果验证的自动化测试。版本 2.1 修订了 Terminal-Bench 2.0 中的 28 个任务，并引入持续验证以提高任务正确性和基准可靠性。我们在 Terminus 2 上评估了 Terminal-Bench 2.1，部分结果收集自 Artificial Analysis。

SWE-Bench Pro [^25] 在长周期、面向企业的软件工程任务上评估编码智能体，这些任务可能需要数小时或数天的专业工作。它包含来自 41 个活跃维护仓库的 1,865 个人工验证问题，分为公开集、保留集和商业集，跨越开源和专有代码库。智能体必须实现大量的、通常是多文件的更改，这些更改需满足特定任务的测试而不破坏现有行为。我们在 Mini-SWE-Agent 上评估了 SWE-Bench Pro，并修改了官方评估镜像以避免智能体从 git 日志中获取真实答案。

SWE-bench Multilingual [^41] [^93] 将 SWE-bench 风格的问题解决扩展到 Python 之外，包含来自 42 个仓库和 9 种编程语言的 300 个人工策划任务：C、C++、Go、Java、JavaScript、TypeScript、PHP、Ruby 和 Rust。每个任务提供一个真实的 GitHub 问题和解决方案前的仓库快照，要求智能体生成一个补丁，该补丁既要通过请求修复的失败到通过 (fail-to-pass) 测试，也要通过现有功能的通过到通过 (pass-to-pass) 测试。它与标准 SWE-bench 评估基础设施保持兼容，同时暴露软件工程性能中的语言特定差异。我们在 Mini-SWE-Agent 上评估了 SWE-Bench Multilingual。

WildClawBench [^26] 是一个原生运行时基准，旨在评估自主 AI 智能体在真实 CLI 执行器环境中执行复杂长周期任务的能力。它将人工编写的双语和多模态工作流与真实工具和环境集成，以测试智能体的端到端工具编排和执行能力。

### 5.2 主要结果

如表 2 和表 3 所示，Intern-S2-Preview-397B 在广泛的科学基准上展示了领先的性能。它在 Biology-Instructions (56.92)、Mol-Instructions (52.37) 和 SciReasoner (63.97) 上优于强大的开源和闭源模型。该模型还在我们内部的 MP20 和 ProteinBinder-9 评估集上达到了最先进 (SOTA) 的结果。此外，它在 MolecularIQ (61.49)、TOMG-Bench (65.66)、XLRS-Bench (51.97) 和 MicroVQA (68.81) 上实现了开源模型中的最佳性能。

##### 时间序列生成

表 5 在 SciTS [^86] 的预测任务上将 Intern-S2-Preview 与通用文本 LLM、视觉-语言 LLM 和专用时间序列预测模型进行基准测试。文本和视觉-语言 LLM 经常表现出低成功率，因为长预测范围可能超出其输出容量，而严格的序列长度和格式要求经常导致指令遵循失败。此外，通过离散文本 token 生成预测可能会损害数值精度，限制其在细粒度科学信号上的准确性。通过采用专用数值预测分支，Intern-S2-Preview-397B 保持了数值保真度，同时能够在异构领域和预测范围内进行可靠预测，优于专用时间序列基线，在 ENG02、ENG03、MEG03、PHG02 和 URG05 上取得了特别明显的提升。范围预测器达到 99% 的准确率，展示了其从预测指令中可靠推断所需预测长度的能力。除了 SciTS 中的科学时间序列任务之外，我们进一步在 GIFT-Eval [^4]（通用时间序列预测基准）上评估 Intern-S2-Preview-397B，它实现了具有竞争力的零样本 MASE 为 0.785。

## 6 结论

我们提出了 Intern-S2-Preview-397B 作为面向科学研究的科学智能体基础模型，它需要多模态理解、领域特定推理、科学生成、工具交互和迭代执行。在科学、多模态、智能体、通用和时间序列评估中，该模型展示了广泛的能力覆盖，并支持架构、预训练和后训练中的主要设计选择。智能体评估进一步表明，科学能力不仅应通过孤立的基准答案准确性来评估，还应通过模型是否能将推理连接到可执行、可验证和迭代的工作流来评估。另外，Memory Decoder 研究表明，针对性的科学专业化可以添加到冻结主干上，同时保留 Intern-S2-Preview-397B 作为通用模型的角色。Intern-S2-Preview 仍是一个预览系统；未来工作应提高在更长科学工作流中的可靠性，扩展领域特定记忆和任务环境，加强验证器，并深化与专业科学工具的集成。
