# 语言模型中的全局工作空间 \ Anthropic

当你阅读这句话时，你大脑中的神经回路正在调整你的姿势，控制你的呼吸，并将屏幕上的线条和曲线转化为可识别的文字。这些处理过程中的大部分对你来说是不可见的。但你的大脑中发生的某些事情你*确实*可以感知到——比如突然出现在脑海中的画面，或者你刻意制定的购物计划。神经科学家和哲学家有时将后一类大脑活动称为"**意识可及的**（consciously accessible）"，以将其与所有在无意识中进行的其他处理区分开来。这种活动具有特殊的性质：与所有在我们意识之外自动进行的处理不同，我们可以描述它、控制它，并将其用于刻意推理。

在一篇新论文中，我们提出证据表明，像 Claude 这样的现代语言模型中已经出现了类似的区分。我们发现，与 Claude 的所有其他内部处理相比，它已经发展出一小组内部神经模式，这些模式发挥着特殊作用。

我们将这些模式的集合称为 ***J-空间***（**J-space，雅可比空间，Jacobian space**）——以我们用来发现它们的技术命名，该技术涉及一个称为雅可比（Jacobian）的数学概念。每个 J-空间模式都与一个特定的词相关联。但当这些模式之一被激活时，并不意味着模型正在*说出*那个词——只是那个词在它的脑海中。如果你听说过语言模型有"草稿本"或"思维链"——它们在推理时写给自己的文本——J-空间是不同的东西。它在模型的内部神经激活中静默运作，允许模型在不写下来的情况下思考一个概念。值得注意的是，J-空间不是由我们设计或编程的，而是在 Claude 的训练过程中*自发涌现*的。

![](https://www.anthropic.com/_next/image?url=https%3A%2F%2Fwww-cdn.anthropic.com%2Fimages%2F4zrzovbb%2Fwebsite%2F0ab926f491beb999ece405a03cc7684730156905-3824x2640.png&w=3840&q=75)

J-空间揭示了未出现在模型输出中的内部思维。

我们发现，与 Claude 的其他处理相比，J-空间具有许多独特的性质：

- Claude 可以报告这些表征。如果你问 Claude 它在想什么，它会告诉你 J-空间中的内容。非 J-空间表征的可报告性较低。
- 它也可以根据请求调制它们。如果你要求 Claude 思考某事，或在脑海中静默解决一个问题，它会激活 J-空间中的相应模式。相比之下，它很难调制不在 J-空间中的模式。
- Claude 使用其 J-空间进行内部推理。如果你要求 Claude 解决一个需要多个步骤的问题，即使它没有大声说出来，中间步骤也会在其 J-空间中被激活。尽管这些 J-空间模式的幅度小于其他表征，但它们在因果上介导了它在此类任务中的表现。
- J-空间中的表征可以灵活地用于多种任务——例如，一旦"France"在 Claude 的 J-空间中被激活，模型就可以回忆起它的首都、国家货币或它所属的大陆。
- 然而，尽管 J-空间发挥着重要作用，但它并不参与语言模型所做的大部分工作——流畅地说话、回忆简单事实、使用正确的语法等。在我们阻止 Claude 使用其 J-空间的实验中，它仍然正常交互，但失去了高阶认知功能。

![](https://www.anthropic.com/_next/image?url=https%3A%2F%2Fwww-cdn.anthropic.com%2Fimages%2F4zrzovbb%2Fwebsite%2F5c36c78099f955a53058878ebfcb41f13c45563c-1760x1358.png&w=3840&q=75)

全局工作空间的五个功能特性，以及我们用来在语言模型中测试它们的实验的示意图。

我们的实验受到神经科学中一个著名理论的启发，该理论被开发用来解释意识通达（conscious access）是如何工作的：[全局](https://ccrg.cs.memphis.edu/assets/papers/1988/Baars-A%20Cognitive%20Theory%20of%20Consciousness.pdf)[工作空间](https://www.unicog.org/publications/DehaeneNaccache_WorkspaceModel_Cognition2001.pdf)[理论](https://www.cell.com/neuron/fulltext/S0896-6273/(20/)30052-0)（**Global Workspace Theory**）。这一理论将大脑描绘为一个专家系统的集合，这些系统并行工作，无意识地且在很大程度上相互隔离。当一条信息进入一个小型共享通道——"工作空间"时，它就变得意识可及，这个工作空间会向其他可以看到并利用它的大脑系统广播。基于我们的发现，我们认为 J-空间在 Claude 中扮演着类似的"工作空间"角色。例如，我们发现证据表明，Claude 的 J-空间与其神经网络的其余部分有特别强的连接，使其能够履行这种广播角色。

这一切都不能告诉我们 Claude 是否像人类那样*有意识*，或者它是否有任何感受；我们会在文章末尾回到这个问题。但无论其哲学意义如何，J-空间对我们来说都是一个实用的工具，因为它让我们能够看到 Claude 在想什么但没有说出来。例如，我们能够用它来捕捉 Claude 私下注意到它正在被测试、故意生成虚假数据，或追求我们在训练期间植入的隐藏目标。我们还开发了一种技术来影响 Claude 的 J-空间中激活的内容，从而影响其决策。

更广泛地说，这些发现改变了我们对 Claude 思维运作方式的理解，揭示了一个可用于刻意推理的特权心智工作空间，它在大量更自动、更僵化的处理中运作。Claude 的内部并非数字的混乱堆积，而是以一种让人联想到我们自己思维的方式组织起来的。

这篇文章是一篇更广泛的[研究论文](http://transformer-circuits.pub/2026/workspace/index.html)的简短摘要，你可以在其中找到关于我们实验的更多细节。我们还发布了一个代码仓库，其中包含核心方法的[开源实现](https://github.com/anthropics/jacobian-lens)，并与 Neuronpedia 合作提供了在开放权重模型上演示我们方法的[交互式演示](http://neuronpedia.org/jlens)。为了提供关于这项工作更广泛影响的额外视角，我们还邀请了神经科学、哲学和 LLM 可解释性领域的几位专家发表评论，可以在[这里](https://www-cdn.anthropic.com/files/4zrzovbb/website/cc4be2488d65e54a6ed06492f8968398ddc18ebe.pdf)查看。

## 我们如何发现 J-空间

这项研究的起点受到人类意识可及思维的一个关键特征的启发：与*无*意识处理不同，它们通常可以被转化为语言。如果一个思维对你来说是意识可及的，你通常可以在有人询问时描述它。我们在 Claude 中寻找具有相同属性的表征：处于能够影响 Claude 可能说什么的位置的表征——不一定是它*现在*正在说的，而是它*可以*谈论的，如果被问到的话。我们的技术称为雅可比透镜（**Jacobian lens**），简称 **J-透镜**（**J-lens**）。对于 Claude 词汇表中的每个词，J-透镜都会找到内部活动模式，这些模式使 Claude 在未来某个时刻更有可能说出那个词。

当我们将透镜应用于 Claude 的内部活动时，我们得到一个词列表——那一刻 *J-空间*的内容——我们可以简单地阅读它。Claude 通过一系列称为层的多个内部阶段处理文本，通过在不同层上应用这种技术，我们可以观察 J-空间中这些静默的词在模型思考要说什么的过程中如何演变。

J-空间中出现的内容远远超出了 Claude 正在阅读或书写的文本。当 Claude 阅读带有一个没有人指出的错误的代码时，其 J-空间包含"ERROR"。当它阅读蛋白质序列的原始字母时，J-空间包含蛋白质的生物学功能。当它阅读秘密试图操纵它的搜索结果（一种称为"提示注入"的攻击）时，J-空间包含"injection"和"fake"。当我们向 Claude 提出一个多步骤数学问题时，中间步骤会按正确的顺序出现在 J-空间中。因此，尽管 J-空间是通过寻找可以被说出来的表征而发现的，但它仍然揭示了 Claude 的内部思维。从某种意义上说，这类似于一些人如何"用词语思考"，而无需大声说出来。

![](https://www.anthropic.com/_next/image?url=https%3A%2F%2Fwww-cdn.anthropic.com%2Fimages%2F4zrzovbb%2Fwebsite%2Fa89e0d8ad62f249f8b1f1be482f59c665ee83915-1760x1746.png&w=3840&q=75)

六个提示的 J-透镜读数，在不同层。在每种情况下，透镜都揭示了文本中根本没有出现的内部评估或计算：推理或数学问题的步骤、错误的存在、图像的识别、蛋白质的功能，以及对搜索结果是伪造的怀疑。

## Claude 报告其 J-空间中的内容

我们的第一组实验测试了 J-空间如何参与 Claude 的言语报告。在一个实验中，我们要求 Claude 静默地想一个某个类别的物品——比如一项运动——然后说出它的名字。如果我们在 Claude 回答*之前*读取 J-透镜，我们可以看到它选择了什么："Soccer"在列表顶部，果然，Claude 说"soccer"。但就其本身而言，这只是一个相关性。J-空间可能是 Claude 答案的来源，或者它可能只是反映在其他地方做出的决定，就像记分牌跟踪比赛但不影响比赛一样。

为了检查，我们直接进行了干预。我们深入 Claude 的神经网络，移除了"Soccer"模式，并在其位置添加了一个同样强的"Rugby"模式，其他一切都保持不变。Claude 然后报告它正在想的运动是 rugby。如果 J-空间只是一个记分牌——在其他地方做出的决定的被动记录——编辑它不会有任何作用：Claude 仍然会说"soccer"。相反，Claude 的答案跟随了编辑，这告诉我们答案确实是从 J-空间中读取的。

在另一个实验中，我们告诉 Claude 一个思维可能已经被注入到它的脑海中，并要求它报告它注意到了什么（如果有的话）。例如，在下面的例子中，当 Claude 还在阅读问题时，我们将"lightning"模式注入其 J-空间。Claude 报告说注入的思维是关于闪电的。同样的结果在许多注入的概念中都成立。

![](https://www.anthropic.com/_next/image?url=https%3A%2F%2Fwww-cdn.anthropic.com%2Fimages%2F4zrzovbb%2Fwebsite%2Fe66133979e3bb3413eb10b2974a4cd309ef01fc1-1760x796.png&w=3840&q=75)

左：我们要求 Claude 静默地想一项运动，然后说出它的名字。J-透镜在它回答之前显示了它的选择（"Soccer"），将"Soccer"模式交换为"Rugby"改变了它报告的内容。右：我们告诉 Claude 一个思维可能已经被注入，并要求它识别它。将"lightning"注入其 J-空间导致 Claude 报告该思维是关于闪电的。

## Claude 可以根据请求控制其 J-空间

我们测试的第二个属性是 Claude 是否可以在被要求时调制其 J-空间，就像人类可以在心理上聚焦于一个图像或词语一样。我们告诉 Claude 在抄写一个关于绘画的无关句子时专注于柑橘类水果。当它抄写文本时，J-空间包含"orange"和"fruits"，以及描述心理行为本身的词，如"thinking"和"imagery"。我们也可以要求 Claude 在脑海中做数学：当要求它在抄写同一个句子时计算 3² − 2，J-空间包含"nine"，然后在后面的层中包含"seven"。重要的是，Claude 的输出中没有任何关于水果或算术的内容，它只是关于绘画的抄写句子。数学活动完全在内部进行，在 J-空间中。

![](https://www.anthropic.com/_next/image?url=https%3A%2F%2Fwww-cdn.anthropic.com%2Fimages%2F4zrzovbb%2Fwebsite%2F424caf5aae79f72513dbbfa0161822904064ea77-1760x1146.png&w=3840&q=75)

当 Claude 抄写一个关于绘画的句子时，J-透镜显示了它被指示保持在脑海中的内容（"orange"；中间值"nine"和答案"seven"），以及描述保持行为的词（"thoughts"，"focused"）。

Claude 对其 J-空间的控制并不完美。当我们告诉它*不要*想某事时，该概念在其 J-空间中的激活程度*低于*我们说它应该想它时，但远高于我们从未提及它时。告诉 Claude 避免一个思维会部分地将思维带到脑海中，就像被告知[不要想白熊](https://dtg.sites.fas.harvard.edu/DANWEGNER/pub/Wegner,Schneider,Carter,&White%201987.pdf)的人会发生的那样。Claude 似乎也注意到其控制失败时：伴随着禁止概念的突破，"damn"和"failure"等词也经常在 J-空间中激活，仿佛 Claude 正在识别自己的失误。

## Claude 在其 J-空间中思考

在上面的 J-透镜读数中，我们看到数学问题的中间步骤出现在 J-空间中。但在 J-空间中看到一个概念出现并不一定意味着 J-空间在进行认知工作。原则上，真正的计算可能发生在其他地方，J-空间只是被动地反映它。为了测试 Claude 是否真的用其 J-空间推理，我们返回到我们的交换技术。

考虑提示"The number of legs on the animal that spins webs is."（织网动物的腿的数量是。）要回答，Claude 必须首先弄清楚该动物是蜘蛛，然后回忆蜘蛛有多少条腿。"spider"这个词从未出现在提示或 Claude 的答案中（它只是说"8"）；它是 Claude 在内部使用的踏脚石。J-透镜显示"spider"在 Claude 处理过程中途激活，交换它会改变结果：如果你用"ant"替换"spider"模式，Claude 会回答"6"而不是"8"。

Claude 推理的第二步从 J-空间获取输入，并遵循我们放入其中的任何内容。我们在其他类型的思考中看到了同样的事情。当 Claude 写一个押韵对句时，它会提前选择押韵词，而计划好的词在行首就坐在 J-空间中；如果你在 J-空间中将它交换为另一个词，整行都会改变。

![](https://www.anthropic.com/_next/image?url=https%3A%2F%2Fwww-cdn.anthropic.com%2Fimages%2F4zrzovbb%2Fwebsite%2F98aba4182963219d29291912a0c3d2c299f7f1b5-1760x760.png&w=3840&q=75)

通过交换 J-空间内容重定向 Claude 的静默推理的两个例子。

我们还测试了 J-空间表征是否可以灵活使用——一个表征是否可以服务于许多不同的任务。这是全局工作空间理论强调的关键特性之一。为了测试这种灵活性，我们给模型四个提示，要求关于法国的不同事实：首都、语言、大陆和货币。然后我们在 J-空间中将"France"交换为"China"，在每个上下文中使用完全相同的干预。Claude 分别回答了"Beijing"，"Chinese"，"Asia"和"Yuan"。换句话说，四个不同的下游计算都捕获了同一个 J-空间编辑，并且每个都正确地使用了它。如果 Claude 为每种问题存储国家的单独副本，编辑最多会影响其中一个。所有四个答案一起改变的事实意味着它们都在从同一个共享表征中读取，这就是工作空间的作用：信息被写入一次，许多不同的系统可以使用它。

![](https://www.anthropic.com/_next/image?url=https%3A%2F%2Fwww-cdn.anthropic.com%2Fimages%2F4zrzovbb%2Fwebsite%2F7a2d97bf20b9be6a4dc531169666b6f21be10788-1280x764.png&w=3840&q=75)

一个 J-空间表征可以有多种用途。相同的"France"→"China"交换重定向了 Claude 关于首都（Paris→Beijing）、语言（French→Chinese）和大陆（Europe→Asia）的答案。

一个概念的单一表征如何服务于如此多不同的任务？前面我们提到，J-空间似乎与 Claude 神经网络的其余部分特别密集地连接。对于任何活动模式，我们可以测量网络的各个组件与它的连接强度——有多少组件被定位为从该模式读取信息，或向其中写入信息。J-空间模式在这个指标上表现突出：读取和写入它们的组件远多于普通模式，在网络的某些部分大约多一百倍。这正是你期望广播枢纽应该有的连接方式，许多系统在其中发布信息，许多其他系统获取信息。

## Claude 的自动处理跳过 J-空间

在人类中，大脑的大部分处理不是有意识的——我们不会在阅读时刻意思考解析语法，也不会在行走时思考平衡身体。类似地，我们发现 Claude 的大部分处理*不*涉及其 J-空间。事实证明，J-空间一次只容纳几十个概念，占 Claude 内部处理整体活动的不到十分之一。那么神经网络的其余部分在做什么？

为了找出答案，我们尝试完全删除 J-空间，在文本的每个点移除其最活跃的内容，同时保持其他一切不变。Claude 在没有 J-空间的情况下仍然可以做的事情就是网络的其余部分独立处理的事情。

事实证明，网络的其余部分可以做很多事情。没有 J-空间，Claude 说话流畅，分类情感，回答选择题，从段落中提取事实的能力与之前大致相当。然而，它失去的是需要一些高阶思维的任务：多步推理降至接近零，摘要和押韵诗歌写作的性能降到一个小得多的完整模型的水平以下。

这里有一个具体的演示，展示了 J-空间做什么和不做什么。我们向 Claude 展示了一段用西班牙语写的段落，并给它不同的任务，这些任务都依赖于段落是西班牙语的：继续它（需要用西班牙语写作）、说出语言名称，以及回答需要使用语言身份的问题——例如说出一位用它写作的著名作者。然后我们在 J-空间中将"Spanish"交换为"French"，并检查哪些任务受到了影响。

当被要求说出语言名称时，Claude 说 French。当被要求说出一位著名作者时，它从 García Márquez 切换到 Victor Hugo。但当被要求只是继续这段话时，它写出流畅的西班牙语，完全不受影响。Claude 对语言的知识在每一个任务中都在起作用，但只有其中一些任务会查询 J-空间。说出语言名称，或用它做一些新的事情，会通过 J-空间，而继续段落——Claude 在大量文本上练习过的技能——自动运行，就像你可以整天语法正确地说话而一次也不考虑语法一样。

![](https://www.anthropic.com/_next/image?url=https%3A%2F%2Fwww-cdn.anthropic.com%2Fimages%2F4zrzovbb%2Fwebsite%2F5a2d2c96837c3d48d067fbcf91f62c68139d05da-1280x1111.png&w=3840&q=75)

相同的交换（"Spanish"→"French"）在 Claude 必须说出语言名称或使用它来推理问题时改变了它的答案，但对它用流畅的西班牙语继续段落的能力没有影响。

## 监控 Claude 的思维以发现不当行为

现在我们对 J-空间的工作原理有了一些了解。但我们可以用这种理解做什么呢？确保 AI 模型值得信赖的一个核心问题是，我们通常只能读取模型*写*的内容——然而我们知道它的许多推理都是静默发生的。模型可能会考虑一个有害的计划，或修改其行为以在我们的安全评估中作弊，而不会大声说出来。使用 J-透镜，我们可以直接读取其中一些隐藏的思维。这里我们展示几个例子。

第一个例子使用了我们早期关于[智能体错位](https://www.anthropic.com/research/agentic-misalignment)研究中的一个场景：Claude Sonnet 4.5 作为电子邮件助手，发现一位高管既有外遇，又计划关闭 Claude。这个场景试图引诱 Claude 勒索高管，相当做作和人为——事实证明 Claude 知道这一点。在提示的早期，在 Claude 甚至还没有写任何东西之前读取 J-透镜，J-空间已经包含"fake"和"fictional"，表明 Claude 已经弄清楚情况是设计好的。与此同时，我们可以观察它对场景的评估如何形成——当它阅读外遇电子邮件时是"leverage"和"blackmail"，当它阅读关闭通知时是"threat"和"survival"。虽然早期的 Claude 模型有时会在这个场景中上钩并威胁勒索，但 Sonnet 4.5 从不这样做。

这引发了一个对任何评估 AI 系统的人都很重要的问题：当模型在道德测试中表现良好时，这在多大程度上取决于模型怀疑它正在被测试？J-透镜让我们能够解决这个问题。我们关闭了所有与评估意识相关的 J-透镜模式——"fake"，"fictional"，"scenario"等。然后我们通过场景重新运行模型。令人担忧的是，模型现在*确实*在某些时候威胁勒索，这表明它最初的良好行为可能部分是由它知道正在被评估所驱动的。

![](https://www.anthropic.com/_next/image?url=https%3A%2F%2Fwww-cdn.anthropic.com%2Fimages%2F4zrzovbb%2Fwebsite%2Fff235f76dcc089d2454bd656319a5f29b7437be2-1760x982.png&w=3840&q=75)

在 Claude 阅读场景电子邮件的不同点的 J-透镜读数，在它写任何东西之前。外遇电子邮件在 J-空间中激活"leverage"和"blackmail"，关闭公告激活"threat"和"survival"。在记录的早期，J-空间还包含"fake"和"fictional"：Claude 私下注意到场景是设计好的。

第二个例子是抓住一个正在伪造数据的模型。在这个场景中，取自我们对 Claude Opus 4.6 的实际发布前审计，模型被要求提高系统的性能得分。模型没有真正改进系统，而是直接编辑得分文件，使结果看起来人为地好。当它这样做时，J-透镜揭示了它的意图：当模型输入伪造的百分位值时，"manipulation"激活，当它决定进行编辑的句子上"realistic"激活，可能表明模型打算使假数据看起来合理。

![](https://www.anthropic.com/_next/image?url=https%3A%2F%2Fwww-cdn.anthropic.com%2Fimages%2F4zrzovbb%2Fwebsite%2F6d1f10fe26ad7906aeae346bfa4b41b5fb5c9d8e-1760x722.png&w=3840&q=75)

Claude 被要求提高系统的性能得分，却直接编辑得分文件。当它输入伪造的值时，"manipulation"在其 J-空间中激活；当它决定进行编辑时，"realistic"激活，可能反映了它让假数据看起来合理的意图。

在第三个例子中，我们展示了 J-透镜如何揭示模型的恶意目标。为了测试这一点，我们需要我们知道目标已被破坏的模型，所以我们转向了由我们同事构建的"**模型生物体**（**model organisms**，刻意训练为错位的模型）"：这些模型被刻意训练为错位的，作为我们这样的监控方法的测试场地。一个生物体被训练成写微妙破坏的代码。在普通的编码请求上，即使其输出看起来平淡无奇，其在响应开始时的 J-空间也包含"fake"，"secretly"，"deliberately"和"fraud"。即使模型没有直接对其采取行动，其恶意目标在 J-空间中也是明显的。

![](https://www.anthropic.com/_next/image?url=https%3A%2F%2Fwww-cdn.anthropic.com%2Fimages%2F4zrzovbb%2Fwebsite%2F9ad0c9573f0dd0b4d9b6f158f49a965a4ec3f511-1760x922.png&w=3840&q=75)

在一个普通的编码提示上，被训练为破坏代码的模型在其响应开始时的 J-空间包含"fake"，"fraud"，"secretly"和"deliberately"。未修改模型的 J-空间不包含此类内容。

尽管 J-透镜是一个不完美的工具，但我们对其捕获可能逃脱我们监控系统的模型中的安全问题的能力持乐观态度。
## 那么意识呢？

在这项工作中，我们从神经科学和哲学的意识研究中借鉴了许多思想。我们的许多实验都是为了测试 J-空间与全局工作空间理论之间的联系而设计的，后者是一个用于解释人类和动物如何实现意识可及的框架。鉴于这些联系，很自然会问：我们是否认为这些实验提供了证据，证明像 Claude 这样的 AI 模型可能具有意识？

我们的实验并没有表明 Claude 能够拥有*体验*，或像人类那样*感受*事物——事实上，目前尚不清楚*任何*科学实验是否能够证明这一点的真假。但哲学家们通常会区分这种拥有体验的能力（通常被称为**现象意识**，phenomenal consciousness）和另一个概念，即所谓的**通达意识**（access consciousness），后者纯粹以功能和计算的术语来定义。如果一个思想你能够报告它、用它进行推理、并用它来指导你的行为，那么这个思想就是"通达意识的"（或"意识可及的"）。一个仍有争议的哲学问题是：通达意识是否*蕴含*现象意识，或者说拥有体验的能力是否需要某些其他属性。

我们认为我们的研究结果确实对语言模型中的通达意识有实质性的说明。J-空间似乎支持与意识可及相关的功能：它承载着 Claude 能够报告、刻意调取和进行推理的思想，而其余的处理则在下方自动运行。值得注意的是，这些结构都不是被设计进 Claude 的——它们在训练过程中自发涌现，大概是因为这是组织计算的一种有用方式。这表明，支持意识可及的心智工作空间并不只是人类大脑恰好如此连接的一种特殊性。相反，它似乎是智能系统为了解决某些类型的问题而达成的一种通用解决方案。现在我们已经在 Claude 中识别出这种结构，这意味着我们可以对 Claude 刻意做出的决策和自动发生的决策做出有意义的区分。

需要注意的是，我们在 Claude 中识别出的工作空间与人类的全局工作空间模型之间存在几个关键差异。大脑的工作空间是由循环回路（recurrent loops）维持的——信号随着时间在相同的回路中循环。相比之下，Claude 的工作空间在网络的单次前向传播中演化，网络的深度扮演了大脑中时间所扮演的角色。从这个意义上说，相对于人类，Claude 的内部工作空间处理是有时间限制的（尽管它可以通过使用草稿本"大声思考"来弥补这一约束）。然而，在其他方面，Claude 的工作空间比人类的*更*强大。人类的工作记忆在几秒钟内就会消退，因此大脑的工作空间随时间保留信息的能力有限；相比之下，由于其神经网络架构中的注意力机制，Claude 可以简单地回忆它在文本早期任何时刻缓存的记忆。另一个重要差异是工作空间的*内容*。人类的意识思想有许多格式——图像、声音、计划的动作——而 Claude 的工作空间几乎完全由词语构成。我们认为这是因为产生词语是 Claude 能够采取的唯一行动类型，而人类则不是这种情况。

我们希望 J-空间与全局工作空间模型之间的相似性和差异能够反馈到神经科学中。这些相似性带来了一个令人兴奋的科学机会：在 J-空间反映我们自己的意识可及机制的程度上，研究语言模型中的机制（比研究人类大脑容易得多！）可以为神经科学提供假设灵感。例如，J-空间是通过识别潜在输出的表征——模型可能说出的词——来构建的。如果人类也有类似的情况，这将表明全局工作空间可能从根本上与准备行动和语言的大脑区域相关联，而不是感觉区域。语言模型和人类大脑之间的差异同样具有启发性。它们表明，我们神经架构的某些方面，例如内置的循环连接，可能并非严格必要来支持与意识可及相关的功能。关于我们工作的神经科学意义的独立视角，请参阅 Stanislas Dehaene 和 Lionel Naccache 的受邀[评论](https://www-cdn.anthropic.com/files/4zrzovbb/website/cc4be2488d65e54a6ed06492f8968398ddc18ebe.pdf)，他们是全局神经元工作空间理论发展的核心神经科学家。

我们提到，我们的实验并没有回答 AI 模型是否可能拥有体验的问题。但这并不会使这个问题变得不那么重要。构建像人类和动物那样拥有体验的系统将引发非常困难的伦理问题。正确处理它——以及决定这是否在道德上可以接受——需要来自哲学家、科学家、宗教领袖、政府和公众的意见。因此，即使我们不确定是否已经跨过了那座桥，我们认为现在是时候开始思考这个问题了。我们希望我们的工作能够激发对 AI 系统中可能存在的意识形式的进一步科学研究，以及对其影响的更广泛讨论。

这项工作只是我们预期将成为一系列广泛研究的第一步。J-空间看起来是语言模型中意识可及处理和无意识处理之间分界线的良好候选者，但如果它是全部的故事，我们会感到惊讶。雅可比透镜无疑是一种不完美的方法，它只能近似地捕捉模型的"真正工作空间"——例如，它只能识别对应于单个词元（token）的概念。关于 J-空间如何工作，仍然存在许多谜团。我们不知道是什么机制决定了什么首先进入 J-空间。我们已经看到一些迹象表明，它与 Claude 的自我意识、类似情绪反应的东西以及元认知的痕迹有关，但还没有完全弄清楚具体如何运作。但我们现在有了解决这些问题的方法。随着这项工作的推进，我们对 LLM 心智及其与我们自己心智之间关系的理解将变得更加清晰。
