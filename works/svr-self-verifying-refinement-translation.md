# SVR：通过联合判定-置信度强化学习实现自适应测试时计算的自我验证精炼

**作者**：Hongyu Chen<sup>1</sup>, Liang Lin<sup>1,2,3</sup>, Guangrun Wang<sup>1,2,3,*</sup>

**单位**：<sup>1</sup> Sun Yat-sen University; <sup>2</sup> Guangdong Key Laboratory of Big Data Analysis and Processing; <sup>3</sup> X-Era AI Lab

**原文链接**：https://arxiv.org/abs/2607.28457

---

## 摘要

扩展测试时计算（test-time compute）可以改进语言模型推理，但统一的计算预算会在简单输入上浪费计算资源，而验证器引导的精炼则依赖外部反馈。我们提出**自我验证精炼**（Self-Verifying Refinement, SVR），一个无预言机的（oracle-free）多轮强化学习框架，学习使用自我验证作为计算控制策略。

在每一轮中，模型生成一个解决方案，同时给出离散的**正确性判定**（verdict：Correct/Incorrect/Unsure）和**置信度分数**（confidence：0-1概率）；仅当判定为正确且置信度超过阈值时，模型才保留当前答案，否则使用自身的自我验证继续精炼。真实正确性仅用于构建训练奖励，从不通过精炼提示暴露给策略，在推理时也无需提供。

SVR 使用 GRPO 在固定视界轨迹（fixed-horizon trajectories）上训练，奖励促进解决方案正确性、校准感知的自我验证和可停止的正确状态；自适应停止（adaptive stopping）仅在推理时激活。

**实验结果**：在七个数学推理基准上，使用 Qwen3.5-2B 的 SVR 达到 **0.563 的宏平均准确率**，平均仅需 **2.99 轮推理**。在评估的完整系统对比中，SVR 超越了标准 GRPO、强多轮基线和固定预算的预言机引导分数反馈参考方法，同时所需轮数远少于固定十轮推理。

**关键词**：自我验证、自适应测试时计算、置信度校准

## 1. 引言

扩展测试时计算已成为改进语言模型推理的核心策略。模型可以将额外的推理计算花费在采样、搜索或迭代精炼上，而不是直接给出单一响应。然而，额外计算的价值高度依赖于具体实例：简单问题可能在一次尝试后就已解决，而困难问题可能需要多次修正。

### 核心问题

**测试时推理不仅是一个扩展问题，也是一个计算分配和保留正确中间答案的问题。**

现有方法的局限：
- **固定预算方法**：为每个输入分配相同计算量，忽视边际价值差异
- **自适应分配方法**：在推理前做出输入级决策，无法逐轮调整
- **自我修正方法**：精炼量由外部指定
- **验证器引导方法**：依赖外部信号（奖励模型、过程验证器、执行结果），部署成本高昂

### 核心挑战

模型的自我验证是自然候选，但存在关键问题：
- **校准误差 → 分配误差**
- 置信度不足 → 正确答案遭受不必要修订
- 过度自信 → 错误轨迹过早终止

### SVR 的解决方案

我们提出将结构化自我验证作为**策略级信号**：

1. **联合输出**：每轮生成（解决方案 + 判定 + 置信度）
2. **自适应停止**：仅当 `verdict = Correct` 且 `confidence ≥ γ` 时停止
3. **无预言机推理**：所有信号来自策略自身，无外部反馈
4. **固定视界训练**：在固定轮数轨迹上训练，推理时才启用自适应

### 主要贡献

1. **SVR 框架**：无预言机的闭环精炼框架，使用策略生成的判定和置信度控制答案保留
2. **联合判定-置信度强化学习**：固定视界多轮目标，聚合轮级信号为轨迹级回报
3. **实验验证**：在7个推理基准上实现更优的准确率-计算权衡，在约一半 token 成本下匹配十样本 GRPO 多数投票

## 2. 相关工作

### 自适应测试时计算

**现有方法**：
- 思维链提示（Chain-of-thought）：引出中间推理步骤
- 自我一致性（Self-consistency）：聚合独立采样路径
- 树结构方法：探索和评估备选推理路径
- Learning How Hard to Think：预测输入-预算对的奖励分布，分配 best-of-k 样本

**局限**：主要基于输入级预测，无法在推理演化过程中动态调整

**SVR 的不同**：将自适应分配移至演化的解决方案状态，使用策略生成的自我验证逐轮决策

### 多轮精炼与强化学习

**现有工作**：
- Reflexion：使用言语反馈和情景记忆
- SCoRe：多轮在线强化学习训练自我修正
- SETS：测试时结合采样、自我验证和自我修正
- MURPHY/iGRPO：扩展 GRPO 到多轮场景
- DeepSeek-R1、VAPO、RLVR：基于结果的强化学习改进推理

**现状**：精炼和轮次级控制仍然分离

**SVR 的创新**：将自我验证集成到多轮强化学习中，同一策略既学习精炼又学习生成控制信号

### 验证与基于置信度的控制

**验证方法**：
- 结果验证器：从采样候选中选择答案
- 过程奖励模型：评估中间推理步骤
- 形式化工具：合成步骤级验证标签

**置信度校准**：
- C3RL：联合优化答案正确性和置信度校准
- CAS：使用置信度分配额外独立样本
- CoRefine：在置信度上训练轻量级控制器

**SVR 的不同**：在推理策略本身中嵌入判定-置信度接口，无需单独验证器或控制器

## 3. 方法论

### 3.1 自适应精炼形式化

**问题设定**：给定输入 $x$，策略 $\pi_\theta$ 使用最多 $T_{\max}$ 轮推理生成候选解决方案序列。

**每轮输出**：
$$o_t = (r_t, a_t, v_t, c_t) \sim \pi_\theta(\cdot | p_t)$$

其中：
- $r_t$：推理轨迹
- $a_t$：任务答案
- $v_t \in \{\mathrm{C}, \mathrm{I}, \mathrm{U}\}$：判定（Correct/Incorrect/Unsure）
- $c_t \in [0,1]$：置信度（答案正确的概率）

**停止规则**：
$$\hat{t}_\gamma = \min\left(\{t \in \{1,\ldots,T_{\max}\}: q_t=0, v_t=\mathrm{C}, c_t \geq \gamma\} \cup \{T_{\max}\}\right)$$

- $q_t$：生成是否被截断的指示器
- $\gamma$：部署阈值（实验中使用 0.85）

**关键特性**：
1. 判定门：防止仅凭置信度触发终止
2. 置信度阈值：控制接受的保守程度
3. 预算保证：最多执行 $T_{\max}$ 轮

### 3.2 无预言机的 SVR 策略

**闭环设计**：单一策略联合产生解决方案和自我评估，无需辅助验证器

**提示构造**（第 $t \geq 2$ 轮）：
$$p_{t+1} = \mathcal{P}_{\mathrm{ref}}(x, d_t, \mathcal{I}(v_t, c_t, q_t))$$

其中：
- $d_t$：长度限制的前一次草稿
- $\mathcal{I}(\cdot)$：状态依赖的精炼指令

**精炼指令分支**：
1. **截断** → 请求全新完整响应
2. **判定 Correct** → 独立重新推导最容易出错的步骤
3. **判定 Incorrect/Unsure** → 错误定位和完整修订

**信息边界**：真实正确性 $y_t$ 永不暴露给策略，训练和推理共享相同接口

### 3.3 学习自我验证控制器

**训练目标**：联合判定-置信度强化学习

**轨迹级回报**：
$$R_{\mathrm{SVR}}(\tau) = \frac{1}{T_{\mathrm{tr}}} \sum_{t=1}^{T_{\mathrm{tr}}} \left(r_{\mathrm{solve},t} + r_{\mathrm{verify},t} + \lambda_{\mathrm{fmt}} r_{\mathrm{fmt},t}\right)$$

**求解组件**：
$$r_{\mathrm{solve},t} = r_{\mathrm{abs},t} + r_{\mathrm{prog},t} - \lambda_{\mathrm{trunc}} q_t$$

- 绝对质量 + 进展奖励 + 截断惩罚
- 奖励正确答案、错误→正确转换
- 惩罚回归和重复失败

**自我验证组件**：
$$r_{\mathrm{verify},t} = (1-q_t)(\lambda_{\mathrm{cal}} r_{\mathrm{cal},t} - \lambda_{\mathrm{over}} r_{\mathrm{over},t} + \lambda_{\mathrm{detect}} r_{\mathrm{detect},t} + \lambda_{\mathrm{ready}} r_{\mathrm{ready},t})$$

四个子项：
1. **校准** $r_{\mathrm{cal},t}$：布赖尔风格，对齐置信度与正确性
2. **过度自信控制** $r_{\mathrm{over},t}$：惩罚错误答案的 Correct 判定
3. **错误检测** $r_{\mathrm{detect},t}$：奖励识别错误
4. **停止就绪** $r_{\mathrm{ready},t}$：促进正确状态的高置信度

**优化**：基于 GRPO 的策略梯度，仅更新最终完成 token

## 4. 实验

### 4.1 实验设置

**模型**：Qwen3.5-2B

**训练领域**：
- Countdown（50K 问题）
- GSM8K（7.5K 问题）
- 竞赛 MATH（7.5K 问题）

**评估基准**（7个）：
- Countdown、GSM8K、MATH500
- AIME26、AMC23、OlympiadBench、MinervaMath

**训练参数**：
- 固定视界：$T_{\mathrm{tr}} = 3$
- 批大小：512（实际问题数）
- 学习率：$5 \times 10^{-7}$
- 温度：1.0（训练）/ 贪婪解码（评估）

**推理参数**：
- 最大轮数：$T_{\max} = 10$
- 置信度阈值：$\gamma = 0.85$
- 贪婪解码

### 4.2 主要结果

**表 1. 自适应 SVR 与基线对比**

| 方法 | All-7 准确率 | 平均轮数 | 累积 Token (×10³) |
|------|-------------|---------|------------------|
| GRPO (单轮) | 0.449 | 1.0 | 3.01 |
| GRPO (10轮固定) | 0.450 | 10.0 | 28.67 |
| 预言机引导参考 | 0.519 | 10.0 | 28.87 |
| **SVR (自适应)** | **0.563** | **2.99** | **8.56** |
| GRPO (10样本投票) | 0.564 | -- | 16.70 |

**关键发现**：
1. SVR 比最强无预言机基线高 **7.5 个百分点**
2. 比预言机引导参考高 **4.4 个百分点**
3. 与10样本投票准确率相当，但仅用 **51% 的 token**
4. 平均仅需 **2.99 轮**，远少于固定10轮

### 4.3 固定预算对比

**关键问题**：自适应优势来自实例依赖的分配，还是仅仅生成更多轮？

**实验**：禁用自适应停止，强制每个样本恰好执行 $K$ 轮 $(K=1,\ldots,10)$

**结果**：
- All-7 最佳固定预算：0.450（在 $K=10$）
- 自适应 SVR：**0.563**（高出 11.3 个百分点）
- **没有单一共享轮数能匹配自适应性能**

**观察**：
- GSM8K 从 $K=1$ 到 $K=2$ 下降 11.6 个百分点（覆盖正确答案）
- 不同基准的最优 $K$ 差异很大（1到10）
- 证明优势来自实例依赖的答案保留

### 4.4 消融实验

**奖励组件消融**：

| 移除组件 | All-7 准确率 | 影响 |
|---------|-------------|------|
| 完整 SVR | 0.563 | 基准 |
| w/o $R_{\mathrm{verify}}$ | 0.528 | -3.5 pp |
| w/o $R_{\mathrm{cal}}$ | 0.536 | -2.7 pp |
| w/o $R_{\mathrm{over}}$ | 0.518 | -4.5 pp |
| w/o $R_{\mathrm{ready}}$ | 0.494 | -6.9 pp |

**关键发现**：
- 所有自我验证组件都贡献性能
- 停止就绪项最关键（GSM8K 从 0.813 降至 0.486）
- 过度自信控制防止错误的过早终止

**结构消融**：

| 变体 | All-7 准确率 | 平均轮数 |
|------|-------------|---------|
| 完整 SVR | 0.563 | 2.99 |
| 单轮 SVR | 0.471 | 1.00 |
| 仅判定 | 0.529 | 2.99 |
| 仅置信度 | 0.482 | 5.99 |

**结论**：迭代精炼和联合判定-置信度都是必要的

### 4.5 置信度阈值扫描

**实验**：扫描 $\gamma \in \{0.50, 0.55, \ldots, 0.95\}$

**结果**：
- 默认 $\gamma = 0.85$ 获得最高聚合准确率
- 过低阈值 → 错误早停增加
- 过高阈值 → 计算增加但准确率下降
- 阈值在基准间迁移性良好

### 4.6 鲁棒性

**3个独立训练种子**（42, 43, 44）：

| 指标 | 均值 ± 标准差 |
|------|--------------|
| All-7 准确率 | 0.556 ± 0.007 |
| 平均轮数 | 3.05 ± 0.06 |
| Token 消耗 | 8.68 ± 0.11 (×10³) |

**结论**：准确率、计算分配和停止行为在种子间一致

## 5. 结论

我们提出了 SVR，一个无预言机的自适应测试时计算框架，通过学习的自我验证实现答案保留和计算分配。

**核心创新**：
1. 策略生成的判定-置信度作为内部控制信号
2. 联合训练目标整合求解和自我验证
3. 固定视界训练 + 自适应推理的解耦设计

**实验证明**：
- 在7个数学推理基准上超越强基线
- 实现更优的准确率-计算权衡
- 无需外部验证器或预言机反馈

**未来方向**：
- 扩展到更大模型和更广泛任务
- 研究判定-置信度表示的替代设计
- 探索与其他测试时计算方法的组合
